# Controlled-server smoke-test

Проверка обязательна перед признанием состава релиза минимальным. Сейчас она не
выполнена: в клиентском репозитории нет разрешённых тестовых endpoint'ов,
канонической `Settings.db3` и безопасного набора тестовых данных.

## Требуемые входные данные

- контролируемый сервер с известным годом и тестовыми документами;
- disposable `Settings.db3` для этого контура;
- входящая в пакет заглушка `admin984.bin`;
- машина/каталог без файлов предыдущей версии;
- Microsoft Word для проверки DOCX.

## Минимальный сценарий

1. Распаковать чистый пакет и проверить его штатным verifier.
2. Убедиться, что рядом с EXE находятся пакетные `Settings.db3` и `admin984.bin`.
3. Запустить клиент из обычного и глубокого кириллического пути.
4. Подтвердить авторизацию `admin`, подключение и серверную регистрацию.
5. Выполнить поиск по каждому настроенному endpoint'у и частичный отказ одного
   из серверов.
6. Открыть текст, путь, приложения и подтверждения строки.
7. Скачать `.tlg`, приложение и DOCX; проверить работу `sht.docm`.
8. Проверить разрешённые служебные загрузки на disposable-данных.
9. Убедиться, что сервер отклоняет неразрешённые операции независимо от
   клиентской заглушки: клиентской ACL больше нет.
10. Зафиксировать фактически открытые файлы/DLL и уточнить release allowlist.

Боевые базы и production-файлы этим тестом не изменяются.
