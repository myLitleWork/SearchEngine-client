## Причина и изменения

На снимке пользователя готовые периоды отображались по алфавиту. В текущей DFM у lstShGroups и lstTemplates стояло `Sorted=True`; это переопределяло уже рассчитанный кодом порядок. У обоих списков выставлено `Sorted=False`, и тот же режим гарантирует инициализация drag-контроллера.

Добавлен `TTemplateListDrag` с нативным `dmAutomatic`, порогом начала перетаскивания VCL и обработчиками Start/Over/Drop/End. Группы переставляются внутри списка групп, шаблоны — внутри выбранной группы. Обычный щелчок, двойной щелчок, выбор шаблона и запуск поиска сохраняют свои обработчики. Перенос между двумя списками не принимается. Выбранная строка после перемещения остаётся выбранной; сброс на свободное место под последней строкой переносит в конец. Отмена и перемещение в ту же позицию не записывают настройки.

Порядок сохраняется атомарно в отдельный `Templates.order.json` рядом с EXE. Файл содержит формат 1, массив групп и отдельные массивы имён шаблонов только для вручную отсортированных групп. `Templates.json`, параметры запросов и формат старых шаблонов при перетаскивании не меняются. При ошибке записи модель остаётся прежней, а контроллер откатывает видимый список и выделение.

Для списка без ручных настроек автоматически применяется порядок «Сегодня → Вчера → Последние 7 дней → Последние 30 дней → Текущий месяц». Приоритет определяется полем периода, для старых записей дополнительно распознаются названия готовых периодов; остальные имена идут по исходной сортировке карты. Группы без ручного порядка идут по именам. Ручной порядок одного списка не влияет на другие. Новые элементы в вручную переставленном списке добавляются после известных; неизвестные, удалённые и повторяющиеся записи порядка игнорируются и не восстанавливают удалённые шаблоны. Повреждённый или неизвестный формат файла порядка вызывает предупреждение и переход на порядок по умолчанию без перезаписи файла при загрузке.

Обновление списков после сохранения/добавления готовых шаблонов теперь использует ту же модель порядка и сохраняет выделение. Инструкции и перечень пользовательских файлов дополнены новым файлом порядка.

Основные места: `TemplateListOrder.h`, `TemplateListDrag.h`, `myRequest.h/.cpp`, загрузка/сохранение порядка и RefreshTemplateLists в `formMain.cpp`, два флага Sorted в `formMain.dfm`. Сервер и wire-протокол не менялись.
