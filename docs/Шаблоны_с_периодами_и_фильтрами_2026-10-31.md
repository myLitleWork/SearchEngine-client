- Дата: 31.10.2026, Asia/Yekaterinburg, UTC+05.
- Checkout: связанная копия `SS_ClientServerBackup/SearchEngine_Cient_asio`.
- Baseline: версия 4.3.80, HEAD `9e89f271a35f6a6f54635b2d2a76cfed214d912e` плюс исходный dirty. Полный список сохранён в `SS_ClientServerBackup/_migration_audit/2026-10-31-template-implementation/baseline.txt`; исходные изменяемые файлы — в `before/`. Предыдущие изменения панели, шрифтов и подсветки сохранены.
- Основание: [оценка периодов](Оценка_шаблонов_по_периодам_2026-10-31.md), затем поручение реализовать рекомендованный вариант с совместимостью, вопросом о фильтрах и справкой в RichEdit.

## Реализовано

1. В верхней панели добавлена группа «Период AutoPad»: без периода, сегодня, вчера, последние 7/30 дней, текущий месяц; выбор даты вх./исх. либо подписи; сортировка «Сначала новые по дате». Используются исключительно поля AutoPad DData/DataPodp. Даты вычисляются при каждом поиске один раз на ПК клиента и передаются всем серверам одинаковыми границами. Выключение SQL сбрасывает период и сортировку по дате.
2. Шаблоны v2 содержат необязательные период, поле даты, SQL-лимит, сортировку и фильтры колонок по именам полей. Сериализация старых пяти полей сохранена. При чтении старого шаблона новые поля имеют значения по умолчанию; при повторной записи неизменённой старой записи новые ключи не добавляются. Применение старого шаблона сохраняет текущие лимит и фильтры таблицы, отключая новый период.
3. При сохранении с выбранным периодом или непустыми фильтрами колонок появляется вопрос «Да / Нет / Отмена»: сохранить фильтры, сохранить без фильтров, отменить операцию. Лимит и сортировка сохраняются отдельно от этого выбора. Новый шаблон без фильтров при применении очищает прежние фильтры колонок. Фильтры колонок применяются локально к уже полученной выборке и повторно применяются после загрузки результата.
4. После успешного сохранения и при выборе шаблона RichEdit показывает группу/имя, запрос (до 160 символов), режим, поле, направление, точность, период, поле даты, лимит, сортировку, сведения о фильтрах и полный путь Templates.json. Сообщение об успехе выводится только после успешной атомарной записи. При ошибке записи восстанавливается прежняя карта шаблонов в памяти.
5. Кнопка «Добавить готовые шаблоны» добавляет и сохраняет группы «Входящие»/«Исходящие», по пять периодов с лимитом 300 и сортировкой по дате. Совпадающие пользовательские имена не заменяются. Порядок известных периодов задан явно. При отсутствии файла готовые шаблоны предлагаются в памяти с первого запуска. Для существующего файла добавление выполняется кнопкой; удалённые записи не восстанавливаются автоматически при старте.
6. SQL поддерживает текстовые даты дд.мм.гггг, ISO и компактные yyyyMMdd. Сборка условия выполняется в `TemplateSearch.h`; имя поля даты ограничено DData/DataPodp. Нового wire-протокола и серверных изменений нет.
7. Обновлены три существующих руководства по шаблонам. Проектный файл и DFM не изменялись этим этапом: новые контролы создаются во время инициализации, учитывают DPI и существующий расчёт ширины панели.

Основные места: `my_json/Request.h`, сериализация в `my_json/ConverterJSON.cpp`, `myRequest.cpp`, `TemplateSearch.h`, `formMain.cpp` (создание контролов, SQL, сохранение/применение, справка), `formMain.h`.

## Статус и ограничения

Реализовано в исходниках и собрано в Debug EXE. Новые параметры, SQL и EhLib-фильтры проверены изолированным нативным тестом. Полный интерфейс главного окна, ручное прохождение модальных вопросов и реальная сеть с рабочими службами не проверялись. Учётные даты рабочих баз не читались. Новые контролы не проходили отдельную проверку на нескольких физических DPI/мониторах.

Лимит остаётся отдельным на сервер и действует по мере обхода баз. Сортировка не гарантирует глобальные последние N среди всех баз/серверов. Для периода через Новый год выбранная группа должна включать службы нужных лет. Это согласованные ограничения предыдущего разбора, отдельная серверная доработка не входила в реализацию.

Версия не повышалась; Release, упаковка и публикация не выполнялись. Совместимость означает чтение старых шаблонов новой программой. Старая программа не умеет интерпретировать новые периоды v2.
