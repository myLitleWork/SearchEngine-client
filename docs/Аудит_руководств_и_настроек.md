## Исправления смысла и ограничения программы

- У клиента нет кнопки «Применить»: уход с вкладки перечитывает данные, очищает выборку и отключает транспорт; применение откладывается на время search/save.
- Подсказка server_year не проверяет год сервера; для server_year разрешены 1000…9999, мастер сервера — 2000…2099.
- Словарь не создаёт произвольный пункт списка Поле; изменение названий отдельно от формы ломает связь.
- В обзоре Обновление! теперь указано как операция выбранного источника, а не безусловно основного.
- Сохранены текущие ограничения: недоступный основной может остановить первичное signed-подключение; порядок колонок не сохраняется; XLS-экспортёр при расширении xlsx; запрос текста не триммирует края. Поведение не исправлялось.

## Дополнительная сверка активных сценариев

- Telega::isSourceConfigured: active требует общий корень, archive принимает общий или явный месячный. При отсутствии месячных баз за прошлый год active может вернуться к ARCHIVE.db3. В выключенном источнике SQL даёт обычный пустой результат, недоступный включённый источник — отдельную ошибку; текстовые карточки выключенного типа пропускаются.
- AddFileCommand создаёт обработку описи только при enable_prm_short_content_autodetect; OUT — подстрока любого участка пути. ignore.txt — список подразделений для описи, не стоп-слова поиска. Краткое содержание PRM обновляется до фильтра подразделения.
- prefix_map.json перечитывается на каждый GET_ATTACHMENTS; prefix и строка map соединяются без автоматического разделителя, имя пользователя сравнивается точно. Все связанные поля и пример перенесены в серверный справочник файлов.

## Подтверждённая по коду проблема поведения (не исправлялась)

GET_ATTACHMENTS (`src/Commands/GetAttachments/GetAttachmentsCmd.cpp`) после чтения файлов вызывает удаление исходного каталога ДО сериализации и отправки ответа. При сбое сериализации/передачи или локальной записи пользователь может потерять одноразовый пакет; обычное получение приложений карточки этим не затрагивается. Риск описан в клиентской служебной операции и серверной карте пакетов. На рабочих данных не воспроизводился; исправление требует отдельного поручения.
