## Изменения

В явный состав пакета добавлен `app/config/search-templates.defaults.json` из проектного `config/`. Он содержит две группы — «Входящие» и «Исходящие», в каждой «Сегодня», «Вчера», «Последние 7 дней», «Последние 30 дней», «Текущий месяц». Используются дата вх./исх. AutoPad, SQL-режим, лимит 300 на сервер, сортировка по дате, фильтры колонок пустые. Значения совпадают с уже реализованными готовыми шаблонами.

Загрузчик использует комплектный файл только при отсутствии пользовательского Templates.json. При наличии личного файла он имеет приоритет и не объединяется с defaults автоматически. Кнопка «Добавить готовые шаблоны» позволяет дополнить личный файл, сохраняя совпадающие пользовательские имена. Личный Templates.json в пакет не включается.

Файл defaults включён в release fingerprint, проверяется до bump на наличие/корректность JSON, копируется по allowlist и становится обязательным для package verifier. Verifier проверяет обе группы, пять периодов каждой, направления и согласованные параметры. Обновлены описание состава поставки и три руководства.
