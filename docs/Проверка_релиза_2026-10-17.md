После уже существовавшего выпуска 4.3.73 выбран следующий номер 4.3.74. Первая попытка остановилась до упаковки: дублирующий ресурс содержал 4.3.1.0. Восстановлена только штатная строка VerInfo_IncludeVerInfo=false для Release|Win32; остальные изменения проекта сохранены. Повтор через tools/release.bat с SEARCHCLIENT_SKIP_VERSION_BUMP=1 успешно выпустил 4.3.74. Исходные formMain.cpp/.h/.dfm побайтно совпали с сохранёнными перед этой работой копиями.

- Ссылки и якоря: 270, все страницы достижимы из оглавления; структура HTML и метаданные проверены.

## Границы проверки

Установка, перезапуск и удаление работающей службы, смена ключей, архивирование рабочих данных и поиск по рабочему серверу не выполнялись. Сверка руководств с кодом и сборка не заменяют эти пользовательские сценарии.

Сохранено предупреждение о существующем GET_ATTACHMENTS: сервер может удалить одноразовый пакет до получения/сохранения ответа клиентом; запрос происходит ещё до выбора локальной папки. В этой задаче поведение не исправлялось.

Прежние опубликованные выпуски не заменялись. Коммиты и push этим заданием не выполнялись.
