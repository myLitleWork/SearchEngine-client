# Группы серверов и сохранение описи — результат изменений

Дата: 7 октября 2026 года. Изменения выполнены в клиенте; версия остаётся 4.3.66. Собрана Win32 Debug. Release и публикация пакета не выполнялись.

## Что изменилось

- Верхний переключатель называется **Сервер / группа**. Подпись расположена над компактным списком в отдельной панели. Он выбирает один источник либо группу, которая может объединять службы разных лет; поиск объединяет ответы её включённых авторизованных источников.
- При смене группы прежняя выборка очищается, соединение и авторизация выполняются заново. Редактирование настроек применяется при выходе из вкладки **Настройки**. Переход **Поиск ↔ Загрузка** сохраняет соединение и результаты.
- При запуске выбирается последняя доступная группа, затем заданная по умолчанию, затем единственная доступная. Если групп несколько и подходящего сохранённого выбора нет, нужен выбор пользователя. Календарный год не переключает группу автоматически.
- **Сохранить базу для описей** всегда предлагает выбрать авторизованный источник, год имени файла и проверить полный путь. Год предлагается из настройки службы, иначе — текущий календарный. Получаемая база принадлежит выбранной службе; ввод года не меняет серверный год данных.
- Если файл уже существует, требуется отметка разрешения на замену. Замена происходит после успешной загрузки через существующий механизм атомарной записи.

Текст, детали и приложения результатов по-прежнему получают с сервера-источника строки. Лимиты остаются отдельными на каждый сервер; устранение дубликатов между серверами не добавлялось. Команды и формат сетевого обмена не менялись.

## Настройки и миграция

| Поле или ключ | Значение |
|---|---|
| `server_ports.god` | Имя группы; историческое имя колонки сохранено для совместимости |
| `server_ports.server_year` | Новая nullable INTEGER-колонка: год службы для предложения имени описи, пусто — неизвестен |
| `settings.last_server_group` | Последняя выбранная группа |
| `settings.default_server_group` | Группа по умолчанию, если последняя недоступна |

Перед добавлением `server_year` в существующую базу создаётся согласованная SQLite-копия `Settings.db3.before-server-groups-<время>.bak` рядом с базой. Затем в транзакции добавляется колонка и в неё переносится четырёхзначное числовое `god`. Произвольные имена остаются с неизвестным годом. Это подсказка, которую нужно сверить с фактической службой.

Повторный запуск не создаёт новую копию для уже обновлённой схемы и не переписывает исправленный `server_year`. Адреса, порты, идентификаторы и флаги сохраняются. При ошибке изменения схема откатывается. Если копию создать нельзя, миграция не продолжается.

При сохранении строки проверяются имя группы, существование `server_id`, диапазон TCP-порта, четырёхзначный год либо пустое значение. Проверка подключения также обнаруживает повтор одного адреса и порта под разными идентификаторами в группе. Разные DNS-имена одного компьютера автоматически не сопоставляются.

Во всех поставляемых таблицах настроек столбцы получили русские подписи. Это изменение отображения: имена SQL-колонок, ключи настроек и схема базы не менялись, дополнительная миграция не требуется.

## Короткая ручная проверка

Для проверки скопируйте обычную рабочую папку клиента в отдельный каталог при закрытой программе и замените в копии EXE на `Win32\Debug\SearchClient_asio.exe`. Проверяется копия `Settings.db3` рядом с этим EXE. Для описи используйте учебные данные: её путь зависит от активного токена и может находиться вне копии папки клиента.

| Действие | Ожидаемый результат |
|---|---|
| Открыть по очереди семь таблиц настроек и проверить верхнюю панель | Все столбцы подписаны по-русски; «Сервер / группа» находится над компактным списком, без наложения на адреса и кнопки |
| Запустить со старой копией настроек, затем перезапустить | Появляется `server_year` и одна резервная копия старой схемы; адреса/порты/флаги сохранены; исправленный год не сбрасывается |
| Создать «Все года» из текущей и архивной служб; подключиться и найти общий учебный запрос | Видны оба адреса и доступ `2/2`; результаты относятся к обоим годам; текст и приложения открываются у правильного источника |
| Переключить группу; закрыть и открыть клиент | Прежняя выборка очищается; запоминается выбранная доступная группа, независимо от календарного года |
| После успешного поиска перейти на «Загрузка» и обратно | Соединение и результаты сохраняются |
| В окне описи выбрать архив с `server_year = 2024`, затем источник с пустым годом | Для архива предлагается `2024.db`; для неизвестного года — текущий год, который можно исправить; путь показан полностью |
| Сохранить учебную опись и повторно открыть окно | Без разрешения заменить существующий файл кнопка недоступна; с разрешением успешная загрузка заменяет файл |
| Прервать доступность учебного источника при повторной загрузке описи | Сообщение об ошибке; содержимое прежнего файла сохранено |
| Проверить сохранение с используемым токеном ПК или USB | База находится по показанному пути рядом с активным токеном; для USB проверить доступность носителя |

Дополнительно при использовании двух серверов одного года: они предлагают одинаковое имя файла. Для сохранения обоих экземпляров первый нужно заранее скопировать отдельно и подписать источником.
