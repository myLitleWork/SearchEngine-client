## Публикация и ограничения

Первый запуск tools/release.bat с публикацией был отклонён автоматической проверкой до создания процесса: настроенное облачное назначение признано недостаточно явно разрешённым для выгрузки пакета. Изменение версии этим отклонённым вызовом не выполнялось. После этого выполнена локальная часть без публикации и без git push. Пользователю предъявлен готовый пакет; 20 октября он явно выбрал «Опубликовать в указанную папку» для SearchClient 4.3.75.

Готовый пакет опубликован штатным `Publish-ReleasePackageIfConfigured.ps1` с версионными именами из `Get-VclAppVersionNames.ps1`, без пересборки и повторного bump.
