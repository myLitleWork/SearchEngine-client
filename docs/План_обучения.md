## Проверка будущих демонстраций

- Начать с короткой последовательности пользователя; настройки и исключения показывать отдельным фрагментом.
- Для группы разных лет различать имя группы, фактический год службы и год локального имени описи.
- Показать список «Шрифт:»: 8…36 пунктов, исходное значение 9, автоматическое сохранение и сохранение размера при смене документа.
- Обновление показывать на полной копии рабочей установки: новые EXE/DLL и комплект руководств, сохранённые настройки, проверка всех функций и период стабильности перед удалением старой папки.
- Пакет пользователя выдаётся одноразово; его запрос выполняется до выбора папки. Не использовать рабочий пакет ради демонстрации отмены или ошибки.
- При DOCX проверить Word и шаблон; при Excel показать возможное предупреждение о формате, PDF получать через доступный PDF-принтер.
