Загрузка файлов и служебные операции

Местный и серверный вход описаны в Подключение и авторизация. Обычное сохранение приложений выбранных карточек — в Сохранение файлов; кнопка Сохранить приложения на вкладке Загрузка получает другой, пользовательский пакет.

Назначение

Вкладка Загрузка объединяет операции, которые обычно нужны для передачи файлов на основной сервер и получения служебных данных пользователя:

  • загрузить файлы «на отправку»;
  • загрузить разноску;
  • сохранить базу для описей;
  • сохранить пакет приложений пользователя;
  • (с верхней панели) запросить обновление базы на выбранном сервере.

Когда её использовать

  • нужно отправить подготовленные файлы на сервер;
  • нужно загрузить файл(ы) разноски;
  • нужно выгрузить базу описи за год выбранной службы в каталог авторизационного файла;
  • нужно забрать пакет приложений, связанный с пользователем;
  • администратор запускает обновление поисковой базы.

Где она находится

  • Вкладка Загрузка — кнопки и список файлов;
  • Верхняя панель — Обновление!

Загрузка файлов, разноски и пакета пользователя выполняется через основной сервер. Для описи отдельно выбирается источник, а обновление при нескольких источниках предлагает выбор сервера.

Что нужно подготовить

  1. Авторизацию и подключение.
  2. Выбранную группу серверов; для описи — нужный источник и год файла.
  3. Файлы для загрузки/разноски.
  4. Для описи — доступный каталог активного авторизационного файла (файл &lt;год&gt;.db пишется туда).
  5. Для пакета приложений — папку назначения.

Для ПК-токена опись сохраняется в %LOCALAPPDATA%\SearchEngine\, для USB — рядом с принятым токеном на флешке, для admin — рядом с EXE. Имя файла — <год>.db; папка должна разрешать запись. Загрузка и пакет пользователя требуют авторизации основного сервера. Опись и обновление требуют доступа к выбранному источнику; успех поиска на другом сервере не обеспечивает их доступность.

Пошаговое использование

Загрузить файлы на отправку

  1. Откройте вкладку Загрузка.
  2. Нажмите Добавить файлы и выберите один или несколько файлов.
  3. При необходимости удалите лишнее через ПКМ → Удалить / Очистить.
  4. Нажмите Загрузить файлы на отправку.
  5. Следите за журналом и прогрессом: успешные файлы помечаются в логе и убираются из списка.
  6. Если сеть оборвётся на одном файле, кнопки снова включатся; в журнале будет не удалось загрузить, диалог ошибки — в UI-потоке. Не закрывайте программу, пока загрузка идёт: закрытие ждёт окончания фоновой задачи.

Загрузить разноску

  1. Нажмите Загрузить разноску.
  2. Выберите файл(ы) в диалоге.
  3. Проверьте строки журнала: успешно загружен или не удалось загрузить с текстом ошибки.

Сохранить базу для описей

Пошаговый отдельный урок: Сохранение описи.

  1. Подключитесь к нужной группе и нажмите Сохранить базу для описей.
  2. Выберите авторизованный источник и проверьте предложенный год файла. Он берётся из server_year; при неизвестном годе предлагается текущий.
  3. Проверьте путь. Если файл существует, разрешите замену, если она нужна.
  4. Нажмите Сохранить и дождитесь сообщения об успехе. Год имени файла не переключает год базы на сервере.

Сохранить приложения (пакет пользователя)

  1. Нажмите Сохранить приложения.
  2. Выберите папку назначения (по умолчанию предлагается каталог активного авторизационного файла).
  3. Дождитесь окна прогресса и сообщения об успехе.
  4. Результат будет в подпапке вида Приложения к шт. ДД.ММ.ГГ.
  5. При ошибке программа предложит повторить попытку.

Обновление базы на сервере

  1. На верхней панели нажмите Обновление!; при нескольких источниках выберите сервер.
  2. При ошибке программа предложит посмотреть подробности в панели текста.
  3. Во время обновления поиск может отвечать Идёт обновление базы.

Параметры функции

Отдельных сложных настроек на вкладке нет. Важны:

Параметр Влияние
Текущий пользователь Имя уходит в операцию пакета приложений; файлы на отправку префиксуются именем пользователя
Сервер / группа Один поисковый источник или набор источников
Год файла описи Отдельный год имени &lt;год&gt;.db; данные приходят с выбранной службы
Основной сервер Загрузка файлов, разноски и пользовательского пакета; исходный выбор в остальных операциях
Папка назначения Куда сохранить пакет приложений

Пример

Пользователь добавляет два файла на вкладке Загрузка, нажимает Загрузить файлы на отправку и в журнале видит … - успешно загружен :) по каждому файлу; список очищается от успешно переданных.

Что происходит после запуска

Клиент передаёт бинарные данные на основной сервер соответствующими командами протокола и показывает локальный журнал/диалоги результата. Для описи новый файл публикуется только после полной записи; пакет приложений создаёт локальные файлы на диске пользователя.

Как понять, что операция завершилась успешно

Операция Признак успеха
Загрузка на отправку Строки успешно загружен в журнале, файлы исчезли из списка
Разноска успешно загружен в журнале
Опись База успешно сохранена - …
Пакет приложений Сохранение завершено успешно! + путь папки
Обновление Нет окна ошибки запроса

Возможные проблемы

Сообщение Что проверить
Ошибка получения базы! / Ошибка при сохранении базы! Связь с выбранным источником описи, права на каталог активного авторизационного файла
Не удалось открыть файл для записи! Путь/права
Папка для сохранения не выбрана. Повторить выбор папки
Ошибка чтения: … Сеть/сервер при загрузке файлов
Ошибка данных: … Некорректный/короткий ответ пакета приложений

Важные замечания и ограничения

  • Клиент не ограничивает эти операции по локальным группам. Сервер обязан проверить пользователя и отклонить недопустимую операцию.

  • Для описи и обновления действует выбранный источник; загрузка файлов, разноски и пакета пользователя использует основной.

  • Сохранение описи заменяет существующий &lt;год&gt;.db в каталоге активного авторизационного файла только после полной записи нового файла; при сбое прежняя база сохраняется.

  • При открытии вкладки Загрузка список файлов и журнал очищаются.

  • Обновление базы может временно блокировать поиск на сервере.

Связанные настройки

Группа, источники, основной сервер, год службы и активный токен/admin — Настройки клиента. Пути файлов — Данные и файлы.
