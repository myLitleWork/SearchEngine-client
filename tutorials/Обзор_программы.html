1. Для чего нужна программа

SearchClient — программа Windows для поиска входящих и исходящих телеграмм на поисковых серверах. Она помогает найти документ по содержимому или учётным сведениям, прочитать текст, посмотреть маршрут, приложения и подтверждения, сохранить нужные файлы и подготовить отчёт.

Клиент обращается к серверу. На сервере находятся индекс текстов, базы AutoPad и сами документы. На компьютере пользователя находятся настройки, шаблоны запросов и временная таблица результатов. Устанавливать сюда серверные базы для обычной работы не требуется.

Одна программа может искать одновременно на нескольких серверах. Выбор группы определяет, к каким службам и портам обращаться. Старый замороженный год можно просматривать тем же клиентом, если архивная служба запущена, добавлена в настройки и разрешает вам доступ.

2. Что нужно перед первым запуском

  1. Распакованный комплект клиента в локальную папку с правом записи. Запускайте app\SearchClient_asio.exe, сохранив остальные файлы комплекта.
  2. Адрес сервера, год и фактический TCP-порт от специалиста, который установил сервер.
  3. Для удалённого сервера — выданный подписанный токен ПК или USB-флешки и разрешение на этом сервере. Для локальной службы на том же компьютере в комплекте предусмотрен admin984.bin.
  4. Для DOCX дополнительно нужны Microsoft Word и поставляемый sht.docm. Для поиска, скачивания исходного текста и приложений Word не требуется.

Надпись «Авторизация : …» подтверждает местный вход. Возможность искать появляется после отдельной успешной авторизации на сервере. Файл admin984.bin обеспечивает местный режим admin; текущий сервер принимает его только при соединении с 127.0.0.1. Он не заменяет токен для работы по сети.

3. Как устроено главное окно

Область Что здесь делать
Верхняя панель Выбрать пользователя/токен и подключение в списке Сервер / группа, подключиться, проверить статус и список адресов с портами, отключиться
Поиск Ввести запрос, выбрать режим, читать результаты и текст, открыть детали, использовать шаблоны, сохранить файлы или отчёт
Загрузка Передать подготовленные файлы на отправку или разноску, получить опись или пакет приложений пользователя
Настройки Настроить каталог серверов и портов, разрешить панель деталей; остальные словари обычно уже заполнены организацией

Обычный пользователь большую часть времени работает на вкладке Поиск. Кнопка Обновление! запрашивает обновление индекса на основном сервере; для каждого поиска нажимать её не нужно.

4. Первый рабочий поиск

  1. Запустите клиент. Выберите нужный токен в верхнем списке, если их несколько.
  2. Проверьте группу серверов. Нажмите Подключение, если автоматическое подключение ещё не выполнено.
  3. Дождитесь статуса авторизовано серверов K/N. Для полноценной выборки нужны все ожидаемые серверы; при K < N поиск охватит только принявшие авторизацию.
  4. Для поиска слов в документе снимите SQL, оставьте OEM-866 включённым и введите слова без внешних точек и кавычек. Для поиска номера или другого поля включите SQL, выберите Вх. либо Исх., поле и значение.
  5. Нажмите Поиск или Ctrl+F. Дождитесь завершения и прочитайте статус: пустой успешный ответ и ошибка сервера означают разное.
  6. Щёлкните найденную строку и прочитайте текст. При необходимости откройте плюсик у строки: Путь:, Приложения:, Подтверждения: для исходящих.
  7. Для скачивания отметьте нужные строки галочками слева, выберите Приложение, tlg или docx, папку и нажмите Сохранить.
  8. Проверьте итоговый журнал и файлы в папке. Для табличного отчёта используйте Экспорт отчета.

Подробные правила двух режимов: поиск и шаблоны. Просмотр и отчёты: работа с результатами. Получение документов: сохранение файлов.

5. Что сохраняется между запусками

Данные Где сохраняются
Серверы, порты, словари, use_f12 Settings.db3 рядом с EXE
Именованные запросы Templates.json рядом с EXE
Сохранённая видимость и ширина колонок DbgEhColumns.ini рядом с EXE, после пункта Сохранить в меню колонок
Токен этого ПК %LOCALAPPDATA%\SearchEngine\searchclient-auth-token.json текущего пользователя Windows
Токен USB На выданной флешке; обычно файл в корне
Размер и положение окна Профиль пользователя Windows
Скачанные файлы и отчёты Выбранные вами папки

SearchRes.db3 содержит временные результаты. Новый поиск, новое подключение и следующий запуск очищают прежнюю выборку. История строк запроса содержит до девяти последних запросов только в текущем сеансе. Год, режим, лимит и папку сохранения проверяйте перед операцией; шаблон запроса сохраняет лишь часть параметров.

При обновлении клиента сохраните свою Settings.db3, Templates.json и DbgEhColumns.ini. Не заменяйте рабочие настройки пустой конфигурацией из нового комплекта. ПК-токен находится в профиле Windows, поэтому простое копирование папки клиента на другой ПК не переносит авторизацию.

6. Как завершить работу

Дождитесь окончания поиска и сохранения. Для прекращения пакетного сохранения нажмите Отмена, дождитесь завершения текущей операции и прочитайте журнал. Уже полученные файлы остаются в папке.

После этого можно закрыть клиент. Отключение разрывает соединения с серверами, но местное имя пользователя может оставаться в окне. Для следующего поиска потребуется подключиться снова.
