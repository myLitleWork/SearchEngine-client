# Руководство по проблемам

Раздел основан на реальных проверках и сообщениях в коде клиента. Общие советы Windows без связи с программой сведены к минимуму.

---

## Нет авторизации

### Симптом

Надпись **Нет авторизации!** не меняется на `Авторизация : …`. Кнопки поиска/сохранения недоступны.

### Возможная причина

- Нет `admin984.bin` рядом с фактически запущенным EXE или имя файла изменено.
- Клиент запущен из другой копии каталога.
- Старый путь содержал кириллицу и использовалась версия клиента до исправления
  Unicode-пути от 08.08.2026.

### Что проверить

1. Откройте в свойствах ярлыка путь к реально запускаемому EXE.
2. Проверьте рядом с ним точное имя `admin984.bin` (не `admin984.bin.txt`).
3. Убедитесь, что это обычный файл, а не каталог с таким именем.

### Что попробовать

1. Разместить отдельно выданную заглушку рядом с EXE.
2. Перезапустить программу и подождать 1–2 секунды.
3. Если используется старая сборка в пути с кириллицей — обновить клиент.

### Когда нужна помощь специалиста

Если заглушка лежит рядом с актуальным EXE, но вход всё равно не выполняется.
Signed-token проверка подписи/серийного номера сейчас отключена.

## Ошибка подключения / нет подключения

### Симптом

Сообщения вида `Ошибка подключения: …`, статус `Статус: нет подключения` / `ошибка подключения` / `ошибка конфигурации`.

### Возможная причина

- Неверный IP/host или порт года.
- Сервер выключен или недоступен по сети.
- Не выбран год / нет строк в `server_ports`.
- Таймаут соединения (2 секунды).

### Что проверить

1. Поле IP и таблицы `servers` / `server_ports`.
2. Выбранный год.
3. Доступность сервера с этого компьютера (по правилам организации).
4. Текст ошибки: `Connection timeout`, `DNS resolution failed`, `Connection failed: …`.

### Что попробовать

1. Исправить host/port и снова нажать **Подключение**.
2. Сменить год на заведомо настроенный.
3. При одном сервере убедиться, что `enabled = 1`.

### Когда нужна помощь специалиста

Если сеть и настройки по инструкции верны, а сервер всё равно не принимает соединение/регистрацию.

## Ошибка регистрации на сервере

### Симптом

`Ошибка регистрации на сервере: …` / `Server rejected USER_REGISTRY: …`

### Возможная причина

Сервер отклонил имя пользователя после TCP-подключения.

### Что проверить

Имя в строке авторизации, доступность основного сервера, актуальна ли учётная запись на стороне сервера.

### Что попробовать

Проверить `admin984.bin`, нажать **Отключение** и **Подключение**, повторить вход.

### Когда нужна помощь специалиста

Если отказ регистрации повторяется для корректного пользователя — нужна проверка серверной стороны.

## Поиск не выполняется

### Симптом

- Кнопка **Поиск** не реагирует при пустом запросе вне SQL.
- Или статус `Поиск не выполнен: 0/N` и список ошибок серверов.
- Или `Ни один сервер не ответил успешно`.

### Возможная причина

Пустой запрос; нет endpoint’ов; сетевые ошибки; на сервере идёт обновление базы (`Идёт обновление базы`); ошибка разбора ответа.

### Что проверить

1. Текст запроса / режим SQL.
2. Статус подключения и год.
3. Текст в окне сообщения по каждому серверу.
4. Не запущено ли обновление базы.

### Что попробовать

1. Повторить поиск позже, если база обновляется.
2. Уменьшить число серверов/проверить их доступность.
3. Для SQL задать поле и корректное значение.
4. Проверить лимит ответов.

### Когда нужна помощь специалиста

Стабильный отказ всех серверов при рабочей сети и верной конфигурации.

## Поиск завершён частично

### Симптом

Сообщение: `Получены ответы от K из N серверов` + список ошибок; статус `Поиск завершён частично: K/N`. В таблице есть часть результатов.

### Возможная причина

Один или несколько серверов недоступны/таймаут/ошибка, остальные ответили.

### Что проверить

Какие серверы перечислены в сообщении и их host/port для текущего года.

### Что попробовать

Работать с полученными результатами; восстановить недоступные серверы и повторить поиск.

### Когда нужна помощь специалиста

Если «падающий» сервер должен быть основным источником данных.

## Файл удалён с диска

### Симптом

`Файл удалён с диска. Доступен только след в индексе поиска.`  
Строка в таблице отображается серым курсивом, в колонке **Статус** — `удалён`.

### Возможная причина

В индексе запись есть, файлового содержимого на сервере уже нет (`deleted != 0`).

### Что проверить

Нужен ли именно файл или достаточно карточки в индексе.

### Что попробовать

Искать другой экземпляр/год/сервер; для удалённых строк сохранение/просмотр текста недоступны.

### Когда нужна помощь специалиста

Если файл должен существовать по регламенту хранения.

---

## Не сохраняются файлы

### Симптом

`Ничего не выбрано!`, `Не выбрано что сохранять!`, `… - дирректория не существует!`, `Не найден шаблон DOCX-макроса: …`, записи в области текста о ошибках скачивания.

### Возможная причина

Не выделены строки; не отмечены Приложение/tlg/docx; неверная папка; нет `sht.docm` для DOCX; сервер не отдал файл; файл уже существует и исчерпаны варианты имён `(N)`.

### Что проверить

1. Выделение строк в таблице.
2. Флажки сохранения.
3. Существование каталога.
4. Наличие `sht.docm` и Word (для docx).
5. Сообщения в области текста (лог сохранения) и прогресс Gauge.

### Что попробовать

Выбрать другую папку; снять docx и сохранить как tlg; повторить при `SERVER_BUSY` (программа делает повторы сама); освободить место на диске.

### Когда нужна помощь специалиста

Повторяющиеся `Сервер не нашёл запрошенный файл` / таймауты передачи при доступном сервере поиска.

## Нельзя закрыть программу

### Симптом

`Дождитесь завершения сохранения файлов.`

### Возможная причина

Идёт фоновое пакетное сохранение (`saveRunning`).

### Что проверить

Прогресс Gauge и сообщения в области текста.

### Что попробовать

Дождаться финальной строки вида `N из M файлов успешно сохранены!`.

### Когда нужна помощь специалиста

Если сохранение «зависло» надолго без прогресса (возможны сетевые ожидания/Word). Не завершайте процесс принудительно без необходимости — могут остаться `.part` файлы.

## Не открываются детали строки (Путь / Приложения / Подтверждения)

### Симптом

`F12` или панель деталей не появляется / неактивна.

### Возможная причина

В `settings` ключ `use_f12` не равен `yes` — при старте панель деталей отключается. Также нужны активные результаты и авторизация.

### Что проверить

Таблицу `settings` на вкладке **Настройки**, наличие строк в таблице результатов.

### Что попробовать

Установить `use_f12 = yes`, перезапустить программу, выполнить поиск, нажать `F12`.

### Когда нужна помощь специалиста

Если после включения ключа панель всё равно недоступна в вашей поставке.

## Приложение недоступно для скачивания

### Симптом

В списке приложений **Доступен = Нет** или сообщение `Файл не доступен для скачивания!`.

### Возможная причина

Сервер сообщил, что файла нет (`exists = false`).

### Что проверить

Колонку **Доступен**, имя файла, тип телеграммы.

### Что попробовать

Скачать другие доступные вложения; уточнить наличие файла на сервере.

## Ошибка при работе с настройками

### Симптом

`Ошибка при загрузке таблиц: …` / `Ошибка при загрузке таблицы: …` / ошибки инициализации/миграции БД.

### Возможная причина

Повреждён или недоступен `Settings.db3`; файл занят; неуспешная миграция со старого `Res.db3`.

### Что проверить

Существует ли `Settings.db3` рядом с exe; не открыт ли он другой программой; текст `Не найден файл базы данных`, `Не удалось удалить старый файл Res.db3…`, `Ошибка миграции`, `Ошибка инициализации баз данных`.

### Что попробовать

Закрыть лишние программы, работающие с базой; восстановить `Settings.db3` из резервной копии; перезапустить клиент.

### Когда нужна помощь специалиста

Любая ошибка миграции/инициализации, после которой программа не стартует.

## Проблемы DOCX

### Симптом

Нет `sht.docm`; в логе сохранения ошибки конвертации; `Word/макрос не завершился за 60 секунд`; `Word не создал выходной DOCX`.

### Возможная причина

Нет шаблона макроса; Word не установлен/заблокирован; макрос не отработал; таймаут 60 с.

### Что проверить

Файл `sht.docm` в каталоге программы, работоспособность Word, антивирусные блокировки макросов.

### Что попробовать

Сохранить как **tlg** вместо docx; закрыть лишние окна Word; повторить на меньшем наборе файлов.

### Когда нужна помощь специалиста

Если макрос организации устарел относительно версии Word.

## Ошибки вкладки «Загрузка»

### Симптом

`Ошибка получения базы!`, `Папка для сохранения не выбрана.`, `Ошибка чтения: …`, строки лога `не удалось загрузить`.

### Возможная причина

Нет связи с основным сервером; отказ операции; не выбрана папка; ошибка передачи файла.

### Что проверить

Авторизацию, статус подключения, журнал `memLogLoad`, путь `admin984.bin` (для
описи файл пишется в каталог текущего авторизационного файла).

### Что попробовать

Повторить операцию; выбрать другую папку; загружать файлы по одному.

## Справочник частых сообщений

| Сообщение | Смысл |
|---|---|
| `Нет авторизации!` | Рядом с запущенным EXE не найден обычный файл `admin984.bin` |
| `Не выбран год поиска` | Пустой список/выбор года |
| `Для … года не настроено ни одного сервера` | Нет enabled endpoint’ов |
| `Идёт обновление базы` | Сервер временно не отдаёт поиск |
| `Ни один сервер не ответил успешно` | Полный отказ fan-out поиска |
| `Получены ответы от K из N серверов` | Частичный успех |
| `Файл удалён с диска…` | Только след в индексе |
| `Ничего не выбрано!` | Нет выделенных строк для сохранения |
| `Не выбрано что сохранять!` | Не отмечены Приложение/tlg/docx |
| `… - дирректория не существует!` | Неверный каталог сохранения |
| `Не найден шаблон DOCX-макроса: …` | Нет `sht.docm` |
| `Дождитесь завершения сохранения файлов.` | Идёт фоновое сохранение |
| `Ошибка запроса: …` | Обёртка над сетевой/серверной ошибкой |
| `Таймаут чтения из сокета (idle 10 с)` | Сервер не присылал данные слишком долго |
| `Connection timeout` | Не удалось установить TCP за 2 с |
| `SERVER_BUSY_ERROR` | Сервер занят; клиент может повторить |
| `Сервер не нашёл запрошенный файл` | Файл отсутствует на стороне сервера |
| `Файл не доступен для скачивания!` | Вложение помечено как недоступное |
| `База успешно сохранена - …` | Опись сохранена |
| `Сохранение завершено успешно!` | Пакет приложений сохранён |
| `Удалить гуруппу '…' со всеми шаблонами?` | Подтверждение удаления группы шаблонов (опечатка в тексте программы) |

Если текст ошибки содержит техническую английскую фразу (`Socket is not connected`, `DNS resolution failed` и т.п.) — это сетевой слой; проверьте соединение и конфигурацию серверов.
