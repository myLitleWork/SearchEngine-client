# Данные и файлы

Документ описывает, какие данные использует SearchClient с точки зрения пользователя: что хранится локально, что приходит с сервера, что можно копировать при переносе программы.

## Какие данные хранит программа

### Локально на компьютере пользователя

| Данные | Назначение |
|---|---|
| Настройки серверов и портов | Куда подключаться и за какие годы |
| Словари полей поиска | Как строить SQL-условия |
| Ключ `use_f12` и др. в `settings` | Режим деталей строки |
| Временные результаты текущего поиска | Таблица на экране |
| Шаблоны запросов | Быстрый повтор типовых поисков |
| Состояние сеанса (флажки, каталог сохранения, история combo) | Часть только до закрытия программы |

### На сервере (не в каталоге клиента)

- Индексы и файлы телеграмм;
- приложения;
- данные пути/подтверждений;
- базы для описей и пакеты приложений пользователя.

Клиент запрашивает их по сети и показывает/сохраняет локально.

## Где находятся файлы

По умолчанию пути считаются от **каталога исполняемого файла** программы.

| Файл / путь | Можно ли удалять | Комментарий |
|---|---|---|
| `Settings.db3` | Нет (потеряете настройки) | Основная локальная конфигурация |
| `SearchRes.db3` | Нежелательно во время работы | Результаты текущего поиска; при старте очищается таблица `res` |
| `Res.db3` (старый) | После успешной миграции удаляется программой | Legacy; при наличии используется для переноса в Settings/SearchRes |
| `SERVER_IP.INI` | Да | Необязательный legacy-файл; адреса хранятся в `Settings.db3` |
| `Templates.json` | Можно, потеряете шаблоны | Создаётся при сохранении шаблонов |
| `admin984.bin` | Нет, входит в релиз | Временный автологин `admin`; обязательный файл текущей поставки |
| `token-HS.bin`, `pubkey.pem`, `prikey.pem` | Текущему режиму не нужны | Signed-token/RSA код временно отключён |
| `sht.docm` | Нет | Обязательный файл релиза для DOCX; макрос Word |
| `%TEMP%\ZipExtractTempN\` | Временные | Распаковка исходящих ZIP |
| `%TEMP%\SCXDOCX-…\` | Временные | Сессия конвертации DOCX |
| `*.part` рядом с целевым файлом | Временные | Незавершённое скачивание |
| `&lt;каталог admin984.bin&gt;\&lt;год&gt;.db` | Результат описи | Создаётся операцией «Сохранить базу для описей» |
| `&lt;выбранная папка&gt;\Приложения к шт. ДД.ММ.ГГ\` | Результат | Пакет приложений |

## Какие файлы программа создаёт и изменяет

**Создаёт / обновляет:**

- `Settings.db3`, `SearchRes.db3` (при инициализации/миграции);
- `Templates.json` при сохранении/удалении шаблонов;
- файлы результатов сохранения (текст, приложения, docx) в выбранной пользователем папке;
- временные файлы в `%TEMP%` и `*.part`;
- базу описи `&lt;год&gt;.db` в каталоге текущего авторизационного файла;
- папку пакета приложений.

**Изменяет без отдельного «Сохранить» в UI настроек:**

- содержимое таблиц `Settings.db3` при правке сетки на вкладке **Настройки** (через Post набора данных);
- `servers.host` для `default` при подключении, если включён ровно один сервер;
- очищает `res` в `SearchRes.db3` при запуске, подключении и новом поиске.

## Какие файлы можно безопасно копировать

Для переноса уже настроенной рабочей конфигурации на другой компьютер поверх
начальной базы из чистого релиза обычно копируют:

- `Settings.db3`;
- `SERVER_IP.INI` (если используете);
- `Templates.json`;

EXE, необходимые библиотеки, `sht.docm` и начальную `Settings.db3` берите из
одного проверенного релизного пакета, а не из старого рабочего каталога.

`admin984.bin` берите из проверенного релизного пакета. Его наличие сейчас
включает локальный режим `admin`; это не заменяет серверную проверку прав.

## Какие файлы нельзя удалять во время работы

- `Settings.db3`, `SearchRes.db3` — программа держит их открытыми;
- `admin984.bin`, пока вы работаете в текущем временном режиме;
- файлы, которые в данный момент скачиваются (`*.part`).

Если миграция не может удалить старый `Res.db3`, программа сообщит, что файл занят другой программой.

## Импорт и экспорт

| Операция | Есть ли | Куда |
|---|---|---|
| Импорт файлов на сервер | Да | вкладка **Загрузка** → загрузка на отправку / разноска |
| Экспорт результатов в отчёт | Да | **Экспорт отчета** (просмотр FastReport) |
| Экспорт в Excel | Да | меню у кнопки экспорта → **Сохранить в excel** |
| Сохранение текста/приложений/DOCX | Да | **Сохранить** на вкладке **Поиск** |
| Пакет приложений пользователя | Да | **Сохранить приложения** |
| База описи | Да | **Сохранить базу для описей** |

Отдельного универсального «экспорта всей локальной БД настроек» в интерфейсе нет — файл `Settings.db3` можно копировать средствами Windows.

## Временные данные и кэш

- Таблица `res` — рабочий кэш результатов текущего поиска, не архив.
- История поля запроса — до 9 значений **только в памяти**.
- TEMP-каталоги ZIP/DOCX — служебные; при нормальном завершении операции очищаются (для ZIP явно удаляется временный каталог).

## Резервное копирование

Встроенной кнопки «Сделать резервную копию» нет. Рекомендуемый ручной минимум перед обновлением/переносом:

1. Закройте программу.
2. Скопируйте `Settings.db3`, `Templates.json` и, только если он используется,
   legacy-файл `SERVER_IP.INI`.
3. При необходимости сохраните пользовательские выгрузки (описи, папки приложений) отдельно от каталога программы.

`SearchRes.db3` обычно не нужно архивировать: содержимое временное.

## Что сохранить перед переносом на другой компьютер

1. Каталог программы целиком (или поставку из релизного пакета).
2. Актуальный `Settings.db3`.
3. `Templates.json`, если шаблоны важны.
4. Инструкцию/адреса серверов и порты по годам (если база настроек ещё не заполнена).
5. Входящий в релиз `admin984.bin`.
6. Для DOCX — Word на новом ПК и `sht.docm`.

После переноса проверьте авторизацию, год, подключение и пробный поиск.

## Ограничения анализа

- Точный состав словарей `map*` зависит от конкретной поставленной `Settings.db3` и не зашит полностью в исходниках как пользовательский справочник.
- Содержимое серверных баз из этого репозитория не анализировалось (сервер — отдельный проект).
- Файлы в исключённых из анализа каталогах (`_db_test`, неотслеживаемые SQL-дампы и т.п.) не использовались как обязательный источник истины для пользователя.
