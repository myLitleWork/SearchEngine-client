# Шаблоны поисковых запросов

### Назначение

Сохраняет часто используемые параметры поиска под именем (в группе) и позволяет быстро применить их снова без ручной настройки полей.

### Когда её использовать

- ежедневно повторяете одни и те же виды поиска;
- нужно быстро переключаться между типовыми запросами;
- хотите сохранить удачную комбинацию SQL/поля/типа.

### Где она находится

Вкладка **Поиск** → группа **Шаблоны**:

- **Показать/скрыть** — открывает/прячет панель шаблонов;
- **Сохранить** — создаёт/обновляет шаблон;
- списки **Группа шаблонов** и **Шаблоны**;
- контекстное меню списка шаблонов → **Удалить**;
- контекстное меню групп → **Удалить**.

Данные хранятся в `Templates.json`.

### Что нужно подготовить

1. Настроить на форме нужные параметры поиска (SQL, тип, поле, точное совпадение, текст).
2. Придумать имена группы и шаблона.

### Пошаговое использование

#### Сохранить шаблон

1. Настройте параметры поиска на форме.
2. При необходимости нажмите **Показать/скрыть**, чтобы открыть панель.
3. Нажмите **Сохранить** в группе шаблонов.
4. Введите имя группы.
5. Введите имя шаблона.
6. Убедитесь, что группа/шаблон появились в списках (файл `Templates.json` обновлён).

#### Применить шаблон

1. Откройте панель шаблонов.
2. Выберите группу.
3. Выберите шаблон в списке (одинарный щелчок применяет параметры).
4. При необходимости запустите **Поиск**.

> Двойной щелчок по шаблону также обрабатывается программой (`lstTemplatesDblClick`) — используйте, если в вашей версии это принято как быстрый выбор.

#### Удалить шаблон / группу

1. Выберите шаблон или группу.
2. ПКМ → **Удалить**.
3. Подтвердите в диалоге.
4. Удаление группы удаляет **все** шаблоны группы.

### Параметры функции

Шаблон сохраняет состояние связанных элементов поиска (поле, текст, признаки SQL/точного совпадения, тип Вх./Исх. — через механизм `myRequest`/`Request`).

Имена группы и шаблона — произвольные непустые строки.

### Пример

Сохраняете группу `Ежедневные`, шаблон `Входящие по номеру` с включённым SQL, типом **Вх.** и полем `Вх/исх №`. На следующий день выбираете этот шаблон, вводите номер и сразу жмёте **Поиск**.

### Что происходит после запуска

Параметры записываются в память программы и в файл `Templates.json` в каталоге программы. При старте файл загружается, если существует.

### Как понять, что операция завершилась успешно

- Имя появилось в списке групп/шаблонов.
- После выбора шаблона поля формы приняли сохранённые значения.
- Файл `Templates.json` обновлён на диске.

### Возможные проблемы

- Пустое имя группы/шаблона — сохранение отменяется.
- Отмена в диалоге удаления — ничего не меняется.
- Повреждённый `Templates.json` — шаблоны могут не загрузиться (поведение зависит от разбора JSON; при проблемах переименуйте файл и создайте шаблоны заново).

### Важные замечания и ограничения

- Удаление необратимо (после подтверждения).
- Текст подтверждения удаления группы содержит опечатку программы: «гуруппу».
- Шаблоны не включают адрес сервера и год.
