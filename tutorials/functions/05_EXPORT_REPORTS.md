# Отчёты и экспорт в Excel

### Назначение

Сформировать печатный/просматриваемый отчёт по текущим результатам поиска и при необходимости сохранить его в файл Excel (`.xlsx`).

### Когда её использовать

- нужно показать или распечатать выборку через FastReport;
- нужно передать таблицу результатов в Excel.

### Где она находится

Вкладка **Поиск**:

- кнопка **Экспорт отчета** — открывает отчёт FastReport;
- контекстное/выпадающее меню у этой кнопки → **Сохранить в excel**.

### Что нужно подготовить

1. Выполнить поиск, чтобы в наборе данных отчёта были строки.
2. При экспорте в Excel — путь для сохранения `.xlsx`.

### Пошаговое использование

#### Просмотр отчёта

1. Выполните поиск.
2. Нажмите **Экспорт отчета**.
3. В окне FastReport просмотрите отчёт.
4. При необходимости используйте возможности предварительного просмотра FastReport (печать/сохранение зависят от доступных действий в окне отчёта).

#### Сохранение в Excel

1. Выполните поиск.
2. Откройте меню у кнопки экспорта и выберите **Сохранить в excel**.
3. Укажите имя файла `*.xlsx`.
4. Дождитесь экспорта; файл обычно открывается после сохранения (`OpenAfterExport = true`).

### Параметры функции

Отдельных пользовательских параметров отчёта в главном окне нет. Состав колонок задан макетом отчёта и включает, в частности:

- № п/п, Тип, Вх/исх. №, Дата вх/исх, Подписной №, Дата подписи, Адресовка, Краткое содержание, Подписал/исполнил.

### Пример

После поиска по исполнителю нажимаете **Экспорт отчета**, проверяете список в предварительном просмотре, затем через **Сохранить в excel** выгружаете файл `results.xlsx` для передачи коллегам.

### Что происходит после запуска

Программа готовит отчёт FastReport по текущему набору результатов и либо показывает его, либо экспортирует через компонент Excel-экспорта в выбранный файл.

### Как понять, что операция завершилась успешно

- Открылось окно отчёта; или
- создан `.xlsx`, и Excel/связанное приложение открыло файл (если ассоциации Windows настроены).

### Возможные проблемы

- Пустой отчёт, если поиск не выполнялся или результаты очищены.
- Отмена диалога сохранения — файл не создаётся.
- Ошибки подготовки отчёта — операция прерывается (`PrepareReport` вернул отказ).

Точные тексты ошибок FastReport зависят от среды и в коде клиента подробно не перехватываются отдельными русскими сообщениями.

### Важные замечания и ограничения

- Это экспорт текущего результата поиска, а не архив всех когда-либо найденных документов.
- Локальная таблица результатов временная.
- Функция не заменяет сохранение исходных файлов телеграмм/приложений.

### Связанные настройки

Прямых настроек экспорта в `Settings.db3` нет.
