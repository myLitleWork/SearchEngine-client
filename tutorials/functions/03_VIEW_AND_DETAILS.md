# Просмотр текста и деталей документа

### Назначение

После поиска можно просмотреть текст телеграммы и связанные сведения: путь документа, список приложений и подтверждения (для исходящих).

### Когда её использовать

- нужно убедиться, что найдена нужная телеграмма;
- нужно посмотреть маршрут/движение документа;
- нужно скачать одно конкретное вложение;
- нужно посмотреть подтверждения исходящего документа.

### Где она находится

Вкладка **Поиск**:

- таблица результатов;
- область текста справа (`rchEdt`);
- панель деталей строки (меню **Путь:** / **Приложения:** / **Подтверждения:**);
- `F12` — показать/скрыть панель деталей;
- контекстное меню текста → **Печать** (`Ctrl+P`);
- кнопка `?` у колонки подписного номера — подставить подписной номер в строку запроса.

### Что нужно подготовить

1. Успешный поиск с результатами.
2. Авторизацию.
3. Для панели деталей — обычно `use_f12 = yes` в настройках (иначе панель может быть отключена при старте).
4. Сетевой доступ к серверу-владельцу строки (`source_server_id` / основной сервер).

### Пошаговое использование

#### Просмотр текста

1. Щёлкните строку в таблице результатов.
2. Дождитесь загрузки текста в правой области.
3. Слова запроса могут быть выделены красным жирным.
4. Если сервер вернул ошибку, программа предлагает посмотреть подробности
   в панели текста: туда попадает сообщение из `config/server-error-messages.json`,
   код и имя ошибки.
5. При необходимости ПКМ по тексту → **Печать**.

#### Открытие деталей

1. Выберите строку.
2. Нажмите `F12` (или откройте панель деталей строки другим доступным способом в сетке).
3. В меню деталей выберите:
   - **Путь:** — таблица движения (номер, дата, время, кому, страница, строка);
   - **Приложения:** — №, имя файла, доступность, размер;
   - **Подтверждения:** — только если тип не `Вх.`
4. Для приложения со значением **Доступен = Да** нажмите кнопку в колонке доступности и укажите путь сохранения.

### Параметры функции

Отдельных «настроек просмотра» мало:

| Параметр | Влияние |
|---|---|
| `use_f12` | Доступность панели деталей |
| Текущий запрос / «Учитывать регистр» | Подсветка слов в тексте |
| Сервер строки | Откуда читаются текст/путь/вложения/ПДТВ |

### Пример

1. Нашли исходящую телеграмму.
2. Выбрали строку — справа появился текст.
3. Нажали `F12` → **Приложения:**.
4. У доступного файла нажали кнопку загрузки и сохранили на диск.
5. Открыли **Подтверждения:** и просмотрели адресатов/файлы.

### Что происходит после запуска

- Текст запрашивается командой чтения файла с сервера-источника строки и перекодируется OEM→ANSI для показа.
- Путь/приложения/ПДТВ запрашиваются отдельными командами у того же сервера-источника.
- Одно вложение сохраняется через диалог выбора файла.
- Удалённые строки (`Статус = удалён`) текст и файлы не отдают — показывается предупреждение.

### Как понять, что операция завершилась успешно

- В правой области виден текст документа.
- В деталях заполнены таблицы пути/приложений/подтверждений.
- При скачивании вложения — сообщение об успешном сохранении с путём и размером.

### Возможные проблемы

| Симптом | Действие |
|---|---|
| Текст не загружается | Проверить авторизацию, `dir` строки, сеть |
| `Файл удалён с диска…` | Содержимое недоступно |
| `Ошибка запроса` + вопрос про подробности | Да — текст из `config/server-error-messages.json` в панели справа; нет — оставить как есть |
| Нет пункта **Подтверждения:** | Для входящих пункт не добавляется |
| `Файл не доступен для скачивания!` | Выбрать другое вложение |
| Панель деталей недоступна | Проверить `use_f12` и перезапуск |

### Важные замечания и ограничения

- Просмотр не изменяет серверные данные.
- Печать относится к тексту в редакторе, а не ко всей таблице результатов.
- `use_f12` управляет только видимостью панели. Право на получение данных
  обязан проверять сервер.
- Загрузка пути и ПДТВ идёт в фоне; закрытие окна дожидается callback и не
  обновляет уже отсоединённый фрейм.
- Сообщения ошибок в модуле подтверждений (ПДТВ) в исходнике частично повреждены кодировкой; пользователь может увидеть нечитаемые строки вместо нормального русского текста.
