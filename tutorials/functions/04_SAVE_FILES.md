# Сохранение файлов результатов

### Назначение

Позволяет скачать на компьютер приложения и/или текст выбранных телеграмм (как `.tlg` или через конвертацию в `.docx`).

### Когда её использовать

- нужно сохранить вложения найденных документов;
- нужно выгрузить тексты телеграмм в файлы;
- нужно получить DOCX через корпоративный макрос Word.

### Где она находится

Вкладка **Поиск**:

- группа **Сохранение** — флажки **Приложение**, **tlg**, **docx**;
- группа **Дирректория** — путь, кнопки **Сохранить** и **Отмена**;
- меню кнопки **Сохранить** → **Сделать отдельную папку**;
- горячая клавиша `Ctrl+S`.

Ход операции отображается в правой текстовой области (лог) и индикатором прогресса.

### Что нужно подготовить

1. Результаты поиска и выделенные строки таблицы.
2. Хотя бы один флажок: Приложение / tlg / docx.
3. Существующую папку назначения (или готовность выбрать её в диалоге).
4. Для **docx**: Microsoft Word и файл `sht.docm` в каталоге программы.
5. Доступ к серверам-владельцам выбранных строк.

### Пошаговое использование

1. Выполните поиск.
2. Выделите нужные строки в таблице (можно несколько).
3. Отметьте, что сохранять:
   - **Приложение** — вложения;
   - **tlg** — текст;
   - **docx** — текст с конвертацией в Word (снимет tlg и наоборот).
4. Укажите каталог или оставьте поле пустым, чтобы выбрать папку в диалоге.
5. При сохранении нескольких строк при необходимости включите **Сделать отдельную папку**.
6. Нажмите **Сохранить** (`Ctrl+S`).
7. Наблюдайте прогресс и сообщения в текстовой области.
8. Чтобы прекратить пакет, нажмите **Отмена**. Текущая операция завершится
   безопасно, временный DOCX будет удалён, новые файлы пакета не запустятся.
9. Дождитесь итогового сообщения об успехе или отмене.

### Параметры функции

| Параметр | Назначение | Рекомендации |
|---|---|---|
| Приложение | Скачать вложения | Если нужны файлы прилож. |
| tlg | Сохранить текст как файл | Без Word |
| docx | Текст → DOCX макросом | Нужны Word и `sht.docm` |
| Каталог | Куда писать | Существующая папка с правами записи |
| Отдельная папка | Подкаталог по тексту запроса | Удобно для пакетной выгрузки |
| Отмена | Остановить текущий пакет | Во время DOCX завершает отдельные Word/worker |

### Пример

Нужно сохранить приложения двух найденных входящих:

1. Выделить две строки.
2. Включить только **Приложение**.
3. Указать `D:\Work\Out`.
4. Нажать **Сохранить**.
5. В логе появляются строки скачивания; файлы оказываются в `D:\Work\Out` (при совпадении имён — с префиксом `(1) `, `(2) ` …).

### Что происходит после запуска

1. Проверяются выделение, флажки, каталог, наличие `sht.docm` (для docx).
2. Для каждой выбранной строки определяется сервер-источник.
3. Удалённые строки и строки без приложений (если не запрошен текст) пропускаются с записью в лог.
4. Входящие приложения скачиваются как отдельные файлы; исходящие — через ZIP с последующей распаковкой нужных имён.
5. Текст скачивается и при необходимости конвертируется в DOCX (таймаут 15 с на обработку Word).
6. Временные файлы (`.part`, TEMP) используются внутри операции.
7. Исходные серверные данные не удаляются; локальные файлы с тем же именем не перезаписываются молча — подбирается новое имя с префиксом.

### Как понять, что операция завершилась успешно

- В логе есть итоговая строка об успешно сохранённых файлах.
- Индикатор прогресса доходит до конца.
- Файлы появились в выбранной папке.
- Интерфейс снова разблокирован; программу можно закрыть.

### Возможные проблемы

| Сообщение / симптом | Что делать |
|---|---|
| `Ничего не выбрано!` | Выделить строки |
| `Не выбрано что сохранять!` | Отметить флажки |
| `дирректория не существует` | Указать существующую папку |
| Нет `sht.docm` | Положить шаблон или сохранить как tlg |
| `Сервер не нашёл запрошенный файл` | Файл отсутствует на сервере |
| Ошибки Word/таймаут 15 с | Проверить Word/макрос; уменьшить пакет |
| Нельзя закрыть программу | Дождаться конца сохранения или нажать **Отмена** |

### Важные замечания и ограничения

- Операция может занимать продолжительное время на больших пакетах и медленной сети.
- Закрытие программы во время сохранения блокируется.
- При отмене уже полностью сохранённые файлы остаются; незавершённый `.part`
  удаляется, а ещё не начатые файлы пропускаются.
- DOCX требует локального Word и доверенного макроса.
- Сохранение не является «экспортом отчёта»; для табличного отчёта используйте отдельную функцию экспорта.
- При многосерверном результате файлы запрашиваются у сервера каждой строки, не обязательно у основного.
