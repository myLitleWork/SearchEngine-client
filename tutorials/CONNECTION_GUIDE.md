# Руководство по подключению к серверам

Это практическое руководство для ежедневной работы. Технические таблицы настроек подробно описаны в [SETTINGS_REFERENCE.md](SETTINGS_REFERENCE.md), сценарий кнопки — в [functions/01_CONNECTION_AND_AUTH.md](functions/01_CONNECTION_AND_AUTH.md).

## Один сервер (типичный случай)

1. В настройках заполните сервер `default` и его адрес в таблице `servers`.
2. Заполните порты лет в `server_ports`.
3. Убедитесь, что есть локальный вход: USB-токен, PC-токен в профиле Windows
   или `admin984.bin` рядом с EXE. При нескольких токенах выберите нужный в списке
   авторизации (или импортируйте подписанный файл).
4. Выберите год, если автоподключение его не выставило.
5. Дождитесь автоподключения или нажмите **Подключение**.

Если сервер один, правка IP при подключении записывается в базу настроек для `default`.

## Несколько серверов

1. На вкладке **Настройки** заполните `servers` и `server_ports` для каждого года.
2. Первый по `sort_order` сервер — основной: на него идут регистрация, обновление базы, опись, загрузки.
3. Поиск выполняется параллельно по всем включённым endpoint’ам года.
4. Текст, путь, приложения и подтверждения конкретной строки запрашиваются у сервера этой строки.

Подробнее: [MULTI_SERVER_SEARCH.md](MULTI_SERVER_SEARCH.md).

## Как понять, что всё готово к поиску

- Есть `Авторизация : …`
- Статус не содержит ошибку/отключение
- Кнопка **Поиск** активна
- Выбран нужный год

## Частые ошибки при подключении

| Ситуация | Действие |
|---|---|
| Остаётся localhost | Заполните `host` в таблице `servers`; `SERVER_IP.INI` не требуется |
| Нет годов в списке | Заполните `server_ports` и выйдите с вкладки настроек |
| Таймаут 2 секунды | Проверьте сеть/адрес/порт |
| Регистрация отклонена | Проверьте пользователя/серверную политику |
| После смены года пропала связь | Дождитесь автопереподключения или нажмите **Подключение** |

## Безопасность

- Не удаляйте входящий в релиз `admin984.bin`: он нужен текущему режиму входа.
- Сейчас это только локальная заглушка: наличие файла включает пользователя
  `admin`, поэтому реальные права обязан независимо проверять сервер.
- Signed-token режим `token-HS.bin` временно отключён; RSA-ключи рядом с EXE не нужны.
- Не публикуйте реальные адреса боевых серверов в открытых документах.
