# Справочник настроек SearchClient

Ниже перечислены настройки, которые пользователь может изменить через интерфейс, файлы рядом с программой или локальную базу `Settings.db3`, а также важные параметры сеанса на вкладке **Поиск**.

Параметры сборки проекта (`.cbproj`) сюда не входят.

---

## Адрес сервера (поле IP)

### Название

Поле в верхней панели (подсказка: `Ip (192.168.10.10)`). В интерфейсе отдельной подписи «Адрес сервера» нет.

### Для чего нужна

Указывает сетевой адрес основного (или единственного) поискового сервера.

### Где находится

Верхняя панель главного окна.

### Возможные значения

- Тип: текст (IP или DNS-имя).
- Пример: `192.168.0.1`, `localhost`.
- При старте по умолчанию используется `localhost`; рабочий адрес берётся из `servers`.

### Какое значение выбрать

Адрес, который сообщил администратор системы. `localhost` имеет смысл только если сервер запущен на этом же компьютере.

### Что изменяет

При подключении, если включён **ровно один** сервер, значение записывается в `servers.host` для `server_id = 'default'`.  
При нескольких включённых серверах адрес из поля IP **не заменяет** весь каталог серверов — список берётся из таблиц `servers` / `server_ports`. После настройки года поле IP синхронизируется с host основного сервера (первого по `sort_order`).

### Когда изменение применяется

При следующем **Подключении** / автоподключении после авторизации / смене года (если выполняется переподключение).

### Где хранится

- краткосрочно — в поле окна;
- при одном сервере — также в `Settings.db3`, таблица `servers`;
- начальное резервное значение — `localhost`.

### Возможные проблемы

Неверный адрес → `Ошибка подключения: …`, статус `нет подключения` / `ошибка подключения`.

### Пример

Ввели `192.168.10.10`, нажали **Подключение** → программа пытается соединиться с этим хостом на порту выбранного года.

## Год поиска

### Название

Выпадающий список годов (рядом с кнопками подключения).

### Для чего нужна

Выбирает, за какой год брать порты и базы серверов.

### Где находится

Верхняя панель.

### Возможные значения

Список формируется из `server_ports` (`DISTINCT god` где `enabled <> 0`), обычно по убыванию. Пустой список означает, что порты не настроены.

### Какое значение выбрать

Год, в котором ожидается нужный документ.

### Что изменяет

Набор endpoint’ов (сервер + порт) для поиска и подключения. При смене года у авторизованного пользователя программа автоматически выполняет переподключение.

### Когда изменение применяется

Сразу при выборе года (с попыткой переподключения, если есть авторизация).

### Где хранится

Список — в `Settings.db3` (`server_ports`). Текущий выбор — в сеансе.

### Возможные проблемы

- `Не выбран год поиска`
- `Для &lt;год&gt; года не настроено ни одного сервера`

### Пример

Выбрали `2025` → поиск идёт только по серверам/портам, настроенным на 2025 год.

## Файл SERVER_IP.INI

### Название

`SERVER_IP.INI`

### Для чего нужна

Необязательный legacy-способ задать начальный адрес сервера. Для новой
настройки файл не нужен: используйте таблицу `servers`.

### Где находится

Файл в каталоге программы (рабочий каталог/рядом с exe).

### Возможные значения

Одна строка — IP или имя хоста.  
Пример верного содержания по сообщению программы: `192.168.0.1`.

### Какое значение выбрать

Адрес основного сервера организации.

### Что изменяет

Значение поля IP при старте. Если каталог `servers` пуст, используется как host для записи `default` / «Основной сервер».

### Когда изменение применяется

При следующем запуске программы (и при первичном seed каталога серверов).

### Где хранится

Текстовый файл рядом с программой. После появления записей в `servers` основным источником адресов становится база настроек.

### Возможные проблемы

Если файл отсутствует, пуст или нечитаем, программа без предупреждения
использует `localhost`. Это нормально; рабочий адрес задаётся в `servers`.

## Таблица servers (каталог серверов)

### Название

Вкладка таблицы `servers` на экране настроек.

### Для чего нужна

Описывает поисковые серверы: идентификатор, отображаемое имя, адрес, включённость, порядок.

### Где находится

**Настройки** → вкладка/таблица `servers` в `tbcSettings`.

### Возможные значения (поля)

| Поле | Смысл |
|---|---|
| `server_id` | Устойчивый идентификатор (например `default`, `archive`) |
| `display_name` | Имя в статусах и сообщениях |
| `host` | IP или DNS |
| `enabled` | `1` — участвует в поиске, `0` — нет |
| `sort_order` | Порядок; **первый** считается основным |

Автосид при пустом каталоге: `default` / `Основной сервер` / host из поля IP / `enabled=1` / `sort_order=0`.

### Какое значение выбрать

Основной сервер — с наименьшим `sort_order`. Архивные/дополнительные — с большим `sort_order` и своими `server_id`.

### Что изменяет

Куда программа подключается и по каким серверам параллельно ищет. Административные операции (обновление базы, опись, загрузка файлов, разноска, пакет приложений) выполняются на **основном** сервере.

### Когда изменение применяется

После выхода со вкладки **Настройки** и следующего подключения или смены года (список годов перечитывается при уходе с настроек).

### Где хранится

`Settings.db3`, таблица `servers`.

### Возможные проблемы

Пустой/выключенный набор → ошибки конфигурации при подключении или поиске.

### Пример

```
default | Основной сервер | 192.0.2.10 | 1 | 0
archive | Архивный        | 192.0.2.20 | 1 | 1
```

## Таблица server_ports (порты по годам)

### Название

Таблица `server_ports`.

### Для чего нужна

Задаёт TCP-порт базы конкретного года на конкретном сервере.

### Где находится

**Настройки** → `server_ports`.

### Возможные значения

| Поле | Смысл |
|---|---|
| `server_id` | Ссылка на `servers.server_id` |
| `god` | Год (строка, например `2025`) |
| `port` | Номер TCP-порта |
| `enabled` | `1` — endpoint включён |

### Какое значение выбрать

Порты, выданные администратором сервера для каждого года и сервера.

### Что изменяет

Состав годов в списке и фактические endpoint’ы поиска.

### Когда изменение применяется

После ухода с вкладки настроек и следующего подключения/смены года.

### Где хранится

`Settings.db3`.

### Возможные проблемы

Нет строк для выбранного года → `Для … года не настроено ни одного сервера`.

## Таблица ports (устаревшая)

### Название

`ports`

### Для чего нужна

Старое соответствие «год → порт» без привязки к нескольким серверам. Используется при первичном переносе в `server_ports` для сервера `default`.

### Где находится

**Настройки** → `ports`.

### Возможные значения

`port`, `god`.

### Какое значение выбрать

Для новых конфигураций предпочтительнее заполнять `server_ports`. Таблицу `ports` можно оставлять для совместимости.

### Что изменяет

При пустом `servers` её строки копируются в `server_ports` для `default`.

### Когда изменение применяется

При первичном seed каталога серверов.

### Где хранится

`Settings.db3`.

## Ключ settings.use_f12

### Название

В таблице `settings`: ключ `use_f12`, значение обычно `yes` или иное.

### Для чего нужна

Включает панель деталей строки (F12).

### Где находится

**Настройки** → таблица `settings`.

### Возможные значения

- `yes` — панель деталей доступна согласно логике `useF12Control`;
- любое другое / отсутствие ключа — контроль выключен; при старте панель деталей строки отключается (`RowDetailPanel->Active = false`).

### Какое значение выбрать

То, что принято в вашей организации. Если детализация строки (Путь / Приложения / Подтверждения) должна быть доступна — обычно требуется `yes`.

### Что изменяет

Только доступность панели деталей. Ключ не является настройкой безопасности и
не даёт пользователю права на серверные данные. Разрешения обязан проверять
сервер.

### Когда изменение применяется

После перезапуска программы (чтение при `FormCreate`).

### Где хранится

`Settings.db3`, таблица `settings`.

### Возможные проблемы

При выключенном `use_f12` пользователь может не открыть детали строки через обычный механизм панели.

## Словари map / map_vh / map_ish

### Название

Таблицы `map`, `map_vh`, `map_ish`.

### Для чего нужна

Сопоставление названий полей интерфейса с условиями SQL для поиска по входящим/исходящим.

### Где находится

**Настройки** → соответствующие таблицы.

### Возможные значения

Поля `Value`, `Key` (текст). Конкретный набор зависит от поставленной базы настроек.

### Какое значение выбрать

Не меняйте без понимания структуры серверных запросов. Неверные соответствия ломают SQL-поиск по полям.

### Что изменяет

Как из выбранного **Поля** и текста запроса собирается условие для сервера.

### Когда изменение применяется

При следующем запуске программы (словари читаются в `FormCreate`).

### Где хранится

`Settings.db3`.

### Возможные проблемы

Пустые/неверные словари → некорректный или пустой SQL-поиск. Точный вид ошибки зависит от ответа сервера.

## Режим SQL

### Название

Флажок **SQL**

### Для чего нужна

Переключает поиск из полнотекстового режима в поиск по полям/SQL-условию.

### Где находится

Вкладка **Поиск** → группа **SQL**.

### Возможные значения

Вкл/выкл. По умолчанию в DFM выключен (параметры SQL при этом неактивны).

### Какое значение выбрать

- Выкл — поиск по тексту запроса (с учётом OEM и регистра).
- Вкл — поиск по выбранному полю или произвольному SQL-фрагменту.

### Что изменяет

- Вкл: отключает OEM, включает тип Вх./Исх., поле, лимит, «Точное совпадение»; на сервер уходят команды поиска Вх./Исх. по SQL.
- Выкл: включает OEM, отключает SQL-параметры; используется команда полнотекстового ответа.

Если SQL включён и строка запроса пуста, программа подставляет поле `SQL` и условие `1=1` (с `order by` / `limit`).

### Когда изменение применяется

На следующем нажатии **Поиск**.

### Где хранится

Только сеанс (может сохраняться в шаблоне `Templates.json`).

## Точное совпадение

### Название

**Точное совпадение**

### Для чего нужна

В SQL-режиме меняет способ построения условия по полю (точное vs более мягкое совпадение — через словари/`SqlCondition`).

### Где находится

Вкладка **Поиск** → группа **SQL**. Активен только при включённом **SQL**.

### Возможные значения

Вкл/выкл.

### Какое значение выбрать

Включайте, когда нужен точный номер/значение без «похожих» совпадений.

### Что изменяет

Текст SQL-условия, отправляемого на сервер.

### Когда изменение применяется

На следующем поиске.

### Где хранится

Сеанс / шаблон.

## Тип (Вх. / Исх.)

### Название

Группа **Тип**: **Вх.** / **Исх.**

### Для чего нужна

Выбор базы входящих или исходящих в SQL-режиме.

### Где находится

Вкладка **Поиск**. Активна при включённом **SQL**.

### Возможные значения

`Вх.` или `Исх.`

По типу искомого документа. Горячие клавиши: `Alt+F1` (Вх.), `Alt+F2` (Исх.).

### Что изменяет

Какая серверная команда используется и какой словарь полей (`map_vh` / `map_ish`).

### Когда изменение применяется

На следующем поиске.

### Где хранится

Сеанс / шаблон.

## Поле поиска

### Название

**Поле:**

### Для чего нужна

Выбор атрибута, по которому строится SQL-условие.

### Где находится

Вкладка **Поиск** → **Параметры запроса**.

### Возможные значения (из интерфейса)

`Вх/исх №`, `Подписной №`, `Кр. содерж.`, `Куда/откуда`, `Подп./исп.`, `Тел. №`, `Дата вх/исх`, `Дата подписи`, `Кол-во прил.`, `Название файла прил.`, `SQL`.

Значение `SQL` означает, что текст запроса используется как фрагмент условия (с добавлением `order by … limit …`).

### Какое значение выбрать

По тому, что известно о документе. Для произвольного условия — `SQL`.

### Что изменяет

Структуру запроса к серверу.

### Когда изменение применяется

На следующем поиске.

### Где хранится

Сеанс / шаблон.

## Максимальное число ответов

### Название

**Максимальное число ответов:**

### Для чего нужна

Ограничивает объём выборки с **каждого** сервера в SQL-режиме.

### Где находится

Вкладка **Поиск** → **Параметры запроса**.

### Возможные значения

В списке: `30`, `60`, `90`, `300`, `600`, `10000`, `9999999`. По умолчанию в интерфейсе: `30`.  
Нечисловое значение обрабатывается как `0` (через безопасное преобразование).

### Какое значение выбрать

- Небольшие значения (30–90) — быстрый поиск «найти несколько».
- Большие — когда нужно шире просмотреть базу; ответ и таблица будут тяжелее.
- Учитывайте: при 3 серверах и лимите 90 теоретически может прийти до 270 строк без удаления дубликатов.

### Что изменяет

`limit` / параметр `SqlCondition::max` в SQL-запросе.

### Когда изменение применяется

На следующем поиске.

### Где хранится

Сеанс / шаблон.

## OEM-866

### Название

**OEM-866**

### Для чего нужна

Перед полнотекстовым поиском перекодирует текст запроса через `AnsiToOem` (кодировка OEM-866).

### Где находится

Рядом с полем запроса. По умолчанию включён. В SQL-режиме принудительно выключается.

### Возможные значения

Вкл/выкл.

### Какое значение выбрать

Обычно оставляйте включённым для обычного текстового поиска, если сервер ожидает OEM. Для SQL режим сам отключает OEM.

### Что изменяет

Байты строки запроса, уходящей на сервер в полнотекстовом режиме.

### Когда изменение применяется

На следующем поиске.

### Где хранится

Сеанс.

## Учитывать регистр символов

### Название

**Учитывать регистр символов**

### Для чего нужна

Если включён — текст запроса не принудительно переводится в верхний регистр перед поиском/подсветкой.

### Где находится

Рядом с полем запроса. В текущей форме элемент **скрыт** (`Visible=False`), поэтому обычный пользователь может не видеть его.

### Возможные значения

Вкл/выкл. По умолчанию выкл (с учётом скрытости — поведение зависит от состояния в DFM/коде).

### Какое значение выбрать

В штатном интерфейсе параметр недоступен; документируется для полноты.

### Что изменяет

Регистр строки запроса и подсветки в тексте.

### Когда изменение применяется

На следующем поиске / загрузке текста.

### Где хранится

Сеанс.

## Параметры сохранения: Приложение / tlg / docx

### Названия

- **Приложение** (`Ctrl+Alt+P`)
- **tlg** (`Ctrl+Alt+T` через действие текста)
- **docx**

### Для чего нужны

Выбор, что скачивать при нажатии **Сохранить**.

### Где находятся

Вкладка **Поиск** → группа **Сохранение**.

### Возможные значения

Независимые флажки, кроме пары **tlg** ↔ **docx**: они взаимоисключающие (включение одного снимает другое).

### Какое значение выбрать

- только текст — **tlg**;
- текст в Word — **docx** (нужны Word и `sht.docm`);
- вложения — **Приложение**;
- можно сочетать приложения с tlg или docx.

Если ничего не отмечено — `Не выбрано что сохранять!`.

### Что изменяет

Набор файлов, запрашиваемых с сервера-владельца строки, и способ обработки текста.

### Когда изменение применяется

На следующем **Сохранить** (`Ctrl+S`).

### Где хранится

Сеанс.

## Сделать отдельную папку

### Название

Пункт меню кнопки **Сохранить**: **Сделать отдельную папку**

### Для чего нужна

При сохранении нескольких выбранных строк создать подпапку по тексту запроса.

### Где находится

Выпадающее меню кнопки **Сохранить**.

### Возможные значения

Вкл/выкл (AutoCheck).

### Какое значение выбрать

Включайте, когда сохраняете пакет результатов одного запроса и хотите не смешивать файлы в общей папке.

### Что изменяет

При числе выбранных строк &gt; 1 создаётся подкаталог: текст запроса, символы `/` заменяются на `-`.

### Когда изменение применяется

На следующем сохранении.

### Где хранится

Сеанс (состояние пункта меню).

## Шаблоны запросов (Templates.json)

### Название

Шаблоны / группы шаблонов.

### Для чего нужна

Сохранить набор параметров поиска (поле, текст, тип, SQL/точное совпадение) под именем и быстро применять его снова.

### Где находится

Вкладка **Поиск** → **Шаблоны** → **Показать/скрыть**, **Сохранить**; списки групп и шаблонов.

### Возможные значения

Произвольные имена группы и шаблона (через InputBox).

### Какое значение выбрать

Понятные имена, например группа «Ежедневные», шаблон «Поиск по номеру».

### Что изменяет

Содержимое `Templates.json` и параметры формы при выборе шаблона.

### Когда изменение применяется

Сохранение — сразу в файл. Применение — сразу при выборе шаблона в списке.

### Где хранится

`Templates.json` рядом с программой.

### Возможные проблемы

Удаление группы необратимо удаляет все её шаблоны (после подтверждения).

## Авторизация (временная файловая заглушка)

### Название

Файл `admin984.bin`.

### Для чего нужна

Временно включает локального пользователя `admin` без ввода логина/пароля.
Файл не определяет серверные права.

### Где находится

`admin984.bin` — рядом с фактически запущенным EXE.

### Возможные значения

Любой обычный файл с точным именем `admin984.bin`; содержимое сейчас не
проверяется. Файл входит в релизный пакет; организация может подменить его
своей копией на рабочем месте.

### Какое значение выбрать

Канонический файл из релиза. Организация может выдать замену для конкретного
рабочего места.

### Что изменяет

Имя пользователя в интерфейсе, регистрацию на сервере, доступность кнопок.
Удаление файла после входа не завершает текущий сеанс `admin`; требуется
перезапуск клиента.

### Когда изменение применяется

Автоматически по таймеру входа (~1,5 с) и выхода (~0,5 с).

### Где хранится

Внешний файл; сеанс хранит имя `admin` и путь заглушки.

### Возможные проблемы

Файл отсутствует, назван иначе, является каталогом или лежит рядом с другой
копией EXE → остаётся **Нет авторизации!** Signed-token режим `token-HS.bin`
временно отключён; RSA-ключи не генерируются и рядом с EXE не нужны.

## Параметры, которые пользователь не видит, но которые влияют на работу

| Параметр | Значение в коде | Эффект |
|---|---|---|
| Таймаут подключения | 2 с | `Connection timeout` |
| Idle-таймаут чтения | 10 с | `Таймаут чтения из сокета (idle 10 с)` |
| Таймаут сохранения файла | 5 с | ошибки `SocketFileSaver` |
| Таймаут DOCX | 15 с | макрос/Word не завершился вовремя |
| История запросов | до 9 | только в памяти сеанса |
| Повторы при SERVER_BUSY | до 5 | повтор скачивания/реконнект |

Эти значения через интерфейс настроек не меняются.
