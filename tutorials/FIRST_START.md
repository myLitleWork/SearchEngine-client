# Первый запуск и настройка серверов

1. Распакуйте Release в отдельную локальную папку и запустите
   `app\SearchClient_asio.exe`.
2. Дождитесь зелёной надписи `Авторизация : admin`.
3. Откройте вкладку **Настройки** → таблицу `servers`. При пустой конфигурации
   клиент создаёт основной сервер `default` с адресом `localhost`. Укажите
   IP-адрес или DNS-имя вашего сервера:

```text
server_id    default
display_name Основной сервер
host         IP-адрес или DNS-имя сервера
enabled      1
sort_order   0
```

4. В пустой конфигурации таблица `server_ports` автоматически получает текущий
   системный год и порт `15000 + последняя цифра года`: например, `2026 → 15006`,
   `2027 → 15007`. Это начальный порт быстрой установки сервера. Если он был
   занят, установщик выбирает следующий свободный — укажите фактический порт
   из результата установки. Для остальных рабочих лет добавьте строки вручную:

```text
server_id default
god       2026
port      15006 (либо фактический порт сервера)
enabled   1
```

5. Перейдите со вкладки **Настройки** на **Поиск**, выберите год и нажмите
   **Подключение**.

`SERVER_IP.INI` создавать не нужно. При его отсутствии программа молча
использует `localhost`, а после настройки берёт адреса из `servers`.

Таблицы `map`, `map_vh` и `map_ish` уже заполнены в Release — не очищайте их.
Таблица `ports` устарела; для новой настройки используйте `server_ports`.
Существующие настройки не перезаписываются; старые строки `ports` переносятся
для `default` без подстановки нового порта. Если прежний клиент уже создал
единственный включённый `default`, но обе таблицы портов пусты, начальная строка
также добавляется при запуске. Настроенные годы не дополняются автоматически
при смене календарного года.

Для нескольких серверов добавьте каждому уникальный `server_id`, строку в
`servers` и отдельную строку нужного года в `server_ports`. Основным считается
включённый сервер с наименьшим `sort_order`.
