# Руководство по поиску

Краткий практический гид. Полное описание функции: [functions/02_SEARCH.md](functions/02_SEARCH.md).

## Какой режим выбрать

| Задача | Режим |
|---|---|
| Найти по фрагменту текста «как есть» | Обычный поиск (SQL выключен), OEM обычно включён |
| Найти по номеру / полю карточки | SQL + нужное **Поле** |
| Нужны только точные значения | SQL + **Точное совпадение** |
| Сложное условие | SQL + поле **SQL** |

## Быстрые клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+F` | Запустить поиск |
| `Alt+F1` | SQL, Вх., поле номера |
| `Alt+F2` | SQL, Исх., поле номера |
| `Alt+F3` | Открыть список полей (в SQL) |
| `F12` | Панель деталей строки |
| `Ctrl+S` | Сохранить выбранное |
| `Ctrl+Alt+P` | Переключить «Приложение» |
| `Ctrl+Alt+T` | Переключить «tlg» |

## Как читать таблицу результатов

Основные колонки:

- **№**, **Тел. №**, **Дата**, **Подписной номер**, **Дата подп.**
- **Краткое содержание**, **Исполнил/подписал**, **Тип**, **Откуда/куда**
- **Выдана**, **Разноска**, **Статус** (`удалён` для отсутствующих файлов)
- **Сервер** (`source_server_id`) — с какого сервера пришла строка

Серый курсив и статус «удалён» означают: в индексе запись есть, файла уже нет.

ПКМ по таблице открывает меню показа/скрытия колонок.

## Частичный успех при нескольких серверах

Если часть серверов не ответила:

1. Результаты успешных серверов всё равно показываются.
2. Появляется список недоступных серверов.
3. Имеет смысл повторить поиск после восстановления связи, особенно если нужный документ мог быть только на недоступном сервере.

Помните: лимит ответов действует на каждый сервер отдельно, дубликаты между серверами не склеиваются.

## После поиска: что делать дальше

1. Выбрать строку и прочитать текст.
2. При необходимости открыть **Путь / Приложения / Подтверждения**.
3. Сохранить файлы или выгрузить отчёт/Excel.
4. Для повторяющихся запросов — сохранить шаблон.
