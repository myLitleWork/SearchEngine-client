Настройки клиента: краткий справочник

Настройка Влияние и применение
servers.server_id Уникальный постоянный идентификатор, на него ссылаются порты
display_name, host Понятное имя и IP/DNS сервера
servers.enabled, server_ports.enabled Для участия нужны оба ненулевых значения
sort_order Первый включённый сервер выбранной группы становится основным; при равенстве — порядок имени и идентификатора
server_ports.god, port Имя группы и фактический TCP-порт службы
server_ports.server_year Год данных службы для подсказки при сохранении описи; пусто — неизвестен
settings.last_server_group Последняя выбранная группа; запоминается клиентом
settings.default_server_group Точное имя группы по умолчанию; используется, если последняя недоступна
ports Старый формат; новый каталог настраивайте в server_ports
settings.use_f12 = yes Разрешает обычную панель деталей; не изменяет права сервера
map, map_vh, map_ish Связь пользовательских названий полей с полями AutoPad; поставляются заполненными
Адреса с портами наверху Показывают подключения выбранной группы; поле ручного IP в текущей форме скрыто, меняйте адрес через servers
Сервер / группа наверху Список под подписью выбирает один источник или группу; смена выбора очищает выборку и выполняет переподключение
SQL, Тип, Поле Режим и источник поиска
Точное совпадение Равенство целого поля AutoPad; не меняет режим всех слов текстового поиска
Максимальное число ответов Положительное число, SQL-лимит отдельно на каждый сервер по всем его базам
OEM-866 Штатная кодировка текстового запроса; выключена в SQL
Шаблон запроса Сохраняет текст, поле, тип, SQL и точность; не сохраняет группу серверов/лимит/OEM
Набор колонок → Сохранить Явно сохраняет ширины и видимость; порядок колонок не записывается
Приложение, tlg, docx Получаемое содержимое; tlg/docx взаимоисключающие
Папка, Сделать отдельную папку Куда сохранять пакет; подпапка по запросу для нескольких отмеченных строк

Завершите редактирование строки настроек и перейдите на Поиск. Клиент перечитает таблицы; прежнее соединение отключается, поэтому нажмите Подключение. Во время поиска/сохранения применение может быть отложено до завершения операции.

Столбцы таблиц подписаны по-русски. Код сервера — server_id, Название сервера — display_name, Адрес сервера — host, Включён — enabled (1 — да, 0 — нет), Порядок — sort_order, Сервер / группа — god, Год службы — server_year. В словарях map* показаны Название для поиска и Поле базы данных, в settings — Настройка и Значение. В старой таблице ports год подписан Год (старый формат). Внутренние имена полей базы остаются прежними.

При обновлении старой схемы server_year добавляется автоматически с резервной копией. Проверьте перенесённые из числового god годы по реальным службам. Подробнее: группы и миграция, опись.

Пошаговые примеры: подключение, поиск, детали и колонки, сохранение.

Проверено по исходникам 7 октября 2026 года. Разделы можно использовать как конспекты отдельных видеоуроков.
