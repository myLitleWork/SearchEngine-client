Откройте Настройки → servers, затем server_ports. Добавление строки клавишей Insert и применение настроек описаны отдельно. Полный пример заполнения: учебная группа «Все года».

Зачем две таблицы и как создать группу

servers хранит код, название, адрес и порядок источника. server_ports связывает этот код с группой, портом и годом службы. Так один источник можно включить в несколько групп, например «Все года» и «2024», а его название и адрес изменить один раз в servers.

Группа создаётся одинаковым именем в столбце «Сервер / группа» таблицы server_ports. Отдельную запись группы в таблице settings создавать не требуется. Имя вводите одинаково во всех строках, без пробелов по краям.

  1. В servers добавьте источники или запишите коды уже существующих. Для разных служб на одном адресе используйте разные коды.
  2. Сохраните последнюю строку переходом в server_ports.
  3. В server_ports добавьте по строке для каждого участника: укажите его код, общее имя группы, фактический порт и год службы.
  4. Поставьте Включён = 1 в обеих таблицах. Вернитесь на «Поиск», выберите созданную группу и нажмите «Подключение».

Чтобы включить существующий источник ещё в одну группу, добавьте строку только в server_ports с тем же кодом, портом и годом службы, указав другое имя группы.

Выбор группы и основного источника

При обычном создании групп last_server_group и default_server_group вручную менять не нужно. Создайте подключения, вернитесь на «Поиск» и выберите группу в списке «Сервер / группа»: клиент запомнит выбор сам.

В текущем сеансе после перечитывания сохраняется ещё доступная выбранная группа. При следующем запуске порядок выбора такой:

  1. Последняя выбранная группа — settings.last_server_group, если она есть в списке.
  2. Группа по умолчанию — settings.default_server_group, если подходящей последней группы нет.
  3. Единственная доступная группа, если предыдущие значения не подходят.
  4. Если групп несколько и подходящего значения нет, выберите группу вручную.

Здесь «доступная» означает наличие группы в списке по включённым записям обеих таблиц. Сетевая недоступность сервера сама по себе не переключает клиента на другую группу.

Чтобы запомнить другую группу для следующего запуска, достаточно выбрать её на «Поиске». Если вы переименовали последнюю группу, после применения настроек выберите новое имя; клиент обновит last_server_group.

Основной — первый включённый источник по порядку, названию и коду. Загрузка, разноска и пакет пользователя обращаются к нему; опись предлагает отдельный источник, обновление при нескольких серверах предлагает выбор. В подписанном режиме недоступность основного может прервать первоначальное подключение до остальных.

Пустой каталог и старый формат

Поставляемая обезличенная база содержит словари, use_f12=yes и пустые подключения. Клиент создаёт источник default с названием «Основной сервер», enabled=1, sort_order=0. Начальный host берётся из первой непустой строки SERVER_IP.INI, иначе localhost. Для действительно пустого каталога без старых ports предлагается текущий год и порт 15000 + последняя цифра года; это не проверка свободного порта.

Таблица ports — старый источник год/порт для первоначального заполнения единственного default. После переноса активные подключения читаются из server_ports; редактирование ports не перенастраивает уже существующий каталог. Пользовательский каталог, включая выключенные строки, не заменяется автоматически, новый календарный год сам не добавляется. Новый чистый файл базы без комплектных словарей не заменяет поставляемую Settings.db3.

При добавлении server_year клиент создаёт согласованную резервную копию; старое четырёхзначное имя группы переносится лишь как подсказка. Миграция и восстановление.

Проверка результата

  1. Завершите строки и вернитесь на «Поиск».
  2. Выберите учебную группу; сверяйте список host:port с действующими службами.
  3. Подключитесь, проверьте K/N, выполните известный учебный запрос.
  4. Для каждого года откройте строку его источника; отдельно проверьте предлагаемое имя файла описи.

Нет группы — проверяйте связи и оба флага. Повтор адреса/порта, неверный порт или год должны быть исправлены до подключения. Смена server_year не выбирает другую серверную базу.

Для SearchClient 4.3.78. Редакция 30 октября 2026 года. Все примеры учебные. Для таблиц на узком экране доступна горизонтальная прокрутка.
