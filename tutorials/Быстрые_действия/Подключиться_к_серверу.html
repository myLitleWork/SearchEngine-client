Быстрое действие

Подключиться к серверу

Цель: Подключиться к настроенной службе и проверить доступ.

Условия

Нужны адрес и порт действующей службы, настроенный Сервер / группа и выбранный способ доступа: Без авторизации для открытого сервера либо подходящий токен для защищённого. Для защищённой службы на этом ПК предусмотрен admin984.bin.

Действия

  1. Запустите app\SearchClient_asio.exe из полного комплекта.
  2. Выберите нужное имя в верхнем списке авторизации. Для открытого сервера выберите Без авторизации. Если защищённому серверу нужен ещё не установленный токен, выберите + Импортировать подписанный токен..., его вид и выданный файл.
  3. Выберите Сервер / группа. Сверьте адреса, фактические порты и годы служб.
  4. Для местного admin проверьте адрес 127.0.0.1; для удалённого защищённого сервера используйте подписанный токен. Открытому серверу токен не требуется.
  5. Нажмите Подключение и дождитесь результата.
  6. Проверьте доступно серверов K/N, без авторизации: M. Для полного охвата нужны все ожидаемые источники.

Ожидаемый результат

При K=N все источники группы разрешили запросы. Местная надпись «Авторизация» сама по себе этого не подтверждает.

Если возникла ошибка

Проверьте токен, доступность основного сервера, адрес, порт и разрешение на отказавшей службе. При K<N выборка будет неполной. Передайте специалисту код ошибки и имя источника.
