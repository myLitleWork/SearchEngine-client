Быстрое действие

Сохранить опись

Цель: Получить базу для описей с одной выбранной службы.

Условия

Подключитесь к группе с нужной авторизованной службой. Каталог активного авторизационного файла должен разрешать запись.

Действия

  1. Откройте Загрузка → Сохранить базу для описей.
  2. Выберите сервер-источник и проверьте фактический год его службы.
  3. Проверьте Год файла описи: подставляется год из клиентской настройки, а при неизвестном годе — текущий календарный.
  4. Прочитайте полный путь <год>.db. Для ПК он находится в %LOCALAPPDATA%\SearchEngine\, для USB — рядом с токеном, для admin — рядом с EXE.
  5. Если файл уже существует, разрешите Заменить существующую базу после успешной загрузки только когда замена нужна.
  6. Нажмите Сохранить, дождитесь сообщения «База успешно сохранена» и проверьте указанный файл.

Ожидаемый результат

Опись выбранной службы записана рядом с активным авторизационным файлом. При ошибке получения или записи прежняя база сохраняется.

Если возникла ошибка

Год имени файла не переключает год сервера; группа «Все года» не объединяет описи. Два источника одного года могут предложить одинаковое имя: первый экземпляр заранее сохраните отдельно. При недоступной кнопке проверьте четырёхзначный год и разрешение замены; при ошибке записи — права, место и подключение флешки.
