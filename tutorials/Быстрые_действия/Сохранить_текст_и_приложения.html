Быстрое действие

Сохранить текст и приложения

Цель: Получить файлы отмеченных документов в выбранную папку.

Условия

Найдите документы, проверьте их источники. Для docx нужны Microsoft Word и sht.docm рядом с EXE.

Действия

  1. Поставьте галочки слева у нужных строк. Просмотр строки курсором её не отмечает; Пробел переключает текущую отметку.
  2. Включите Приложение и нужный текстовый формат: tlg либо docx. Эти два формата взаимоисключающие.
  3. В Сохранение документов укажите существующую папку с правом записи; пустое поле вызовет выбор папки.
  4. Для нескольких строк при необходимости выберите в меню Сохранить → Сделать отдельную папку.
  5. Нажмите Сохранить или Ctrl+S и дождитесь окончания.
  6. Прочитайте журнал, откройте текст и все ожидаемые приложения из конечной папки.

Ожидаемый результат

Получены выбранные файлы. Пакет подбирает свободные имена при совпадении; повтор может создать дополнительные копии.

Если возникла ошибка

«Ничего не выбрано!» требует галочек строк, «Не выбрано что сохранять!» — формата. Завершённый прогресс не исключает ошибок. У исходящего «Доступен = Да» подтверждает ZIP, а не каждую запись. DOCX преобразует текст и не включает приложения автоматически. Отмена останавливает дальнейшие задания; уже полученные файлы остаются. Кнопка «Сохранить приложения» на вкладке «Загрузка» выдаёт отдельный одноразовый пакет пользователя.
