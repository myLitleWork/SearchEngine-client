Быстрое действие

Сделать отчёт

Цель: Подготовить отчёт по текущей выборке.

Условия

Выполните поиск, проверьте полноту ответа источников и нужные строки. Для PDF нужен установленный PDF-принтер.

Действия

  1. Подготовьте состав выборки поиском и локальными фильтрами таблицы.
  2. Нажмите Экспорт отчета.
  3. В предварительном просмотре проверьте строки, страницы и поля; при необходимости распечатайте.
  4. Для Excel откройте контекстное меню кнопки экспорта → Сохранить в excel.
  5. Задайте имя файла, дождитесь экспорта и откройте результат для проверки.
  6. Для PDF из просмотра отчёта выберите печать, PDF-принтер, страницы и имя файла; затем откройте полученный PDF.

Ожидаемый результат

Получен отчёт с заданным программой макетом либо экспортированная таблица. Галочки сохранения документов и экранный «Набор колонок» не определяют макет отчёта.

Если возникла ошибка

Если строки не те, проверьте исходную выборку и фильтры. Фильтр не получает документы сверх серверного лимита. Диалог Excel предлагает .xlsx, но используется XLS-экспортёр: при предупреждении о формате проверьте открытие и пересохраните через Excel. Прямого PDF-экспорта нет; без PDF-принтера используйте доступную печать. Отчёт не включает полный текст и приложения.
