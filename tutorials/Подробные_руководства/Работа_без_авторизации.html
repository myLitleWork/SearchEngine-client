Работа без авторизации

Для сервера с общим доступом ключи, токен ПК, флешка и регистрация пользователя не нужны. Режим доступа задаёт администратор каждого сервера.

Подключение

  1. Запустите клиент и выберите в верхнем списке Без авторизации. Если доступных токенов и местного admin нет, этот вариант выбирается автоматически.
  2. Выберите нужный Сервер / группа. Проверьте адреса, порты и годы в настройках подключений.
  3. Нажмите Подключение. Открытые серверы разрешат запросы без проверки токена.
  4. В строке состояния проверьте «доступно серверов K/N, без авторизации: M». При K меньше N часть источников не участвует в поиске.
  5. Найдите и откройте заранее известный документ. Возможность поиска и чтения определяется ответом сервера.

В этом режиме отсутствие токена или флешки не блокирует поиск и не вызывает выход по таймеру. Для перехода к защищённому серверу выберите подходящий токен ПК/USB либо местного admin и подключитесь снова.

Чтобы перейти от оператора к общему доступу, выберите Без авторизации и нажмите Подключение. Предыдущее соединение закроется, а данные токена будут убраны из текущей сессии. Установленный токен ПК или вставленная флешка не меняют выбранный режим.

Смешанная группа

Одна группа может содержать открытые и защищённые серверы. С выбранным токеном клиент проверит его только там, где это требуется; к открытым источникам подключится без отправки подписи. С выбранным «Без авторизации» доступны только открытые источники. Остальные будут перечислены как недоступные; выборка по группе окажется неполной.

Отказ защищённого сервера не переводит его в открытый режим. Старые серверы без объявления общего доступа требуют обычный вход. При изменении серверного режима переподключитесь.

Рабочие операции

Поиск, чтение текстов и приложений карточки, сохранение и получение описи выполняются обычным способом. При загрузке на сервер в журнале и папке отправки будет общее имя unauthenticated_user и IP вашего компьютера.

Служебный одноразовый пакет может быть настроен администратором как общий буфер unauthenticated_user. Без такой настройки он недоступен. Получение удаляет серверный буфер до передачи ответа; заранее нужна отдельная копия. К обычным приложениям карточек это не относится.

Если подключение отклонено

Сообщение «Сервер требует авторизацию» означает, что этому экземпляру нужен токен. Выберите выданное имя в списке либо уточните серверный режим у администратора. Если сервер открыт, проверьте его фактический адрес, порт и доступность сети. Имя режима на клиенте само по себе настройки сервера не меняет.
