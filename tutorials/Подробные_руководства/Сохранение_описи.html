Быстрые действия: Сохранить опись

Кнопка Сохранить базу для описей на вкладке Загрузка получает базу с выбранной поисковой службы. Это отдельная операция; она не сохраняет найденные документы и не объединяет описи нескольких серверов.

Все темы: Все руководства. Подключения: группы серверов. Остальные операции вкладки: загрузка и служебные операции.

1. Подготовка

  1. В списке Сервер / группа выберите нужное подключение и подключитесь.
  2. Проверьте авторизацию источника, с которого нужна опись.
  3. Узнайте год этой службы. Если в настройках заполнен server_ports.server_year, клиент предложит его в окне сохранения. Это год, указанный в клиенте, а не автоматически прочитанный с сервера.

Сервер отдаёт свой файл <год службы>.db из настроенного каталога описи. Выбор группы «Все года» не заставляет одну службу отдавать базы всех лет.

2. Последовательное сохранение

  1. Откройте Загрузка → Сохранить базу для описей.
  2. Выберите сервер-источник из авторизованных подключений текущей группы. По умолчанию выбран основной; если он не авторизован, выбирается первый доступный.
  3. Проверьте Год файла описи. При смене источника клиент заново подставляет его server_year. Если год неизвестен, предлагает текущий календарный год — проверьте и исправьте его.
  4. Прочитайте показанный полный путь файла. Четырёхзначный год задаёт имя, например 2024.db.
  5. Если такой файл существует, отметьте Заменить существующую базу после успешной загрузки, если намерены заменить его. До этого кнопка Сохранить недоступна.
  6. Нажмите Сохранить, дождитесь сообщения об успехе и проверьте файл по указанному пути.

Ввод года меняет имя локального файла, но не выбирает другой год на сервере. Для получения описи 2024 года выберите службу, которая действительно обслуживает 2024 год. Если её нет в группе, добавьте подключение либо переключите группу.

При ошибке получения или записи прежняя база сохраняется. Источник и путь фиксируются перед фоновой загрузкой. Не закрывайте клиент и не отключайте носитель до её завершения.

3. Куда записывается база

Активный способ входа Каталог файла <год>.db
Токен ПК %LOCALAPPDATA%\SearchEngine\ текущего пользователя Windows
Токен USB Рядом с используемым токеном на флешке
Местный admin Рядом с запущенным EXE

Это не папка обычного сохранения документов. Каталог должен разрешать запись. Имя группы не используется в имени описи.

Два сервера одного года могут содержать разные базы, но предложить одинаковое имя 2024.db. Сохранение второго заменит первый файл только при выбранном разрешении на замену. Если нужны оба, предварительно сохраните первый экземпляр отдельно и подпишите его источником.

5. Если сохранить не получилось

  • Нет источников в окне: подключитесь и проверьте разрешение на нужной службе.
  • Кнопка недоступна: укажите четырёхзначный год; проверьте, требуется ли разрешить замену.
  • Ошибка получения: проверьте сервер, его файл описи и права доступа.
  • Ошибка записи: проверьте каталог активного токена, свободное место и доступность флешки.

Передайте специалисту имя сервера, фактический год службы и сообщение ошибки. Успешный поиск на другом источнике не означает, что опись выбранного сервера доступна.

Для SearchClient 4.3.74. Редакция 17 октября 2026 года. Все примеры учебные. Для таблиц на узком экране доступна горизонтальная прокрутка.
