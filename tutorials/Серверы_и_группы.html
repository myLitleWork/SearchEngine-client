Группы серверов: один запрос по нескольким годам

Группа — заранее настроенный набор из одного или нескольких поисковых подключений. В окне он выбирается списком Сервер / группа, расположенным под одноимённой подписью. Его имя может быть годом (2026), названием отдела или диапазоном (Архив 2024–2025, Все года). Имя группы не меняет год работающей службы. Службы разных лет можно объединить и искать по ним одним запросом.

Все темы: Все руководства. Авторизация: Подключение и авторизация. Отдельная операция: сохранение описи.

1. Если подключения уже настроены

  1. Выберите Сервер / группа в верхней части окна.
  2. Проверьте показанные рядом адреса и порты.
  3. Нажмите Подключение, если соединения ещё нет. При смене группы клиент очищает прежнюю выборку, переподключается и повторяет авторизацию.
  4. Проверьте K/N: сколько источников приняли ваш токен. Частичный доступ даёт неполный охват.
  5. Выполните обычный текстовый или AutoPad-запрос. Клиент объединит успешные ответы включённых авторизованных источников.

Лимиты действуют на каждом сервере отдельно. Одинаковые документы разных источников автоматически не удаляются из общей выборки. Текст, детали и приложения каждой строки запрашиваются у её источника.

2. Как настроить учебную группу «Все года»

Используйте фактические порты своих служб. Ниже — пример трёх служб на одном компьютере; для удалённого компьютера замените адрес и используйте выданный токен.

В Настройки → servers:

Код сервера Название сервера Адрес сервера Включён Порядок
archive2024 Архив 2024 127.0.0.1 1 10
archive2025 Архив 2025 127.0.0.1 1 20
current2026 Текущий 2026 127.0.0.1 1 0

В server_ports:

Код сервера Сервер / группа TCP-порт Год службы Включён
archive2024 Все года 15004 2024 1
archive2025 Все года 15005 2025 1
current2026 Все года 15006 2026 1
  1. Создайте строки servers, затем связанные строки server_ports.
  2. Для всех участников задайте точно одинаковое имя в столбце Сервер / группа (god). Пробелы по краям не допускаются. Код сервера соответствует server_id, Год службы — server_year; в Включён задайте 1.
  3. Завершите редактирование переходом на другую строку. Вернитесь на Поиск.
  4. Выберите Все года, подключитесь и проверьте три адреса и статус 3/3.
  5. Введите учебное слово, присутствующее в документах каждого года. Откройте по одному результату разных лет и проверьте дату и источник.

Двум службам разных лет на одном адресе нужны разные server_id, поскольку в одной группе один идентификатор имеет один порт. Не включайте тот же адрес и порт дважды под разными идентификаторами: клиент обнаруживает такое повторение.

Для отдельного поиска только по 2024 году можно добавить строку archive2024 с god = 2024, тем же портом и server_year = 2024. Один источник может входить в несколько групп. Его год службы должен быть согласован во всех этих строках.

3. Основной сервер и участие источников

Участие требует enabled <> 0 в обеих таблицах. Группа без включённых серверов не показывается в списке. Основным становится первый по servers.sort_order, затем по имени и идентификатору.

Загрузка файлов, разноски и пользовательского пакета использует основной сервер. Обновление базы при нескольких источниках предлагает выбрать сервер. Сохранение описи всегда открывает окно выбора источника и года файла; по умолчанию выбирается основной авторизованный источник.

В подписанном режиме первоначальное соединение сначала проверяет основной сервер. Если он недоступен, подключение может остановиться до проверки остальных. Назначьте доступный источник основным либо восстановите его работу.

4. Что выбирается при следующем запуске

Клиент использует последнюю доступную группу (settings.last_server_group), затем группу по умолчанию (settings.default_server_group). Если доступна только одна группа, выбирает её. Если групп несколько и подходящего сохранённого выбора нет, просит выбрать группу и подключиться.

Значение настройки — точное имя группы из god. После переименования обновите default_server_group; последняя выбранная группа запомнится при выборе/настройке подключения. Смена календарного года не дополняет каталог и не переводит пользователя на другой источник.

5. Что происходит при обновлении старого клиента

Имена старых групп-годов, адреса, порты и флаги сохраняются. В server_ports автоматически добавляется server_year. Перед изменением существующей схемы создаётся SQLite-копия Settings.db3.before-server-groups-<время>.bak рядом с базой.

Старое четырёхзначное god переносится в server_year как подсказка. Для произвольного имени год остаётся неизвестным. Проверьте подсказку по фактической настройке службы: числовое имя группы само по себе не доказывает год данных. Повторный запуск не перезаписывает исправленный год.

Для восстановления закройте клиент, сохраните нынешнюю базу отдельно и восстановите нужную резервную копию как Settings.db3. При запуске нового клиента старой схемы миграция выполнится вновь. Шаблоны запросов и пользовательские файлы этим изменением не затрагиваются.

Короткие видео

  • Группа из одного сервера: выбор и подключение.
  • «Все года»: один запрос, три службы, независимые лимиты.
  • Основной сервер, неполный доступ и переключение группы.

Группы серверов и группы шаблонов — разные настройки. Шаблон запроса не сохраняет выбранную группу источников.

Проверено по исходникам 7 октября 2026 года. Разделы можно использовать как конспекты отдельных видеоуроков.
